# 一 · 基础构件

## 蜡烛线的画法

`图3.3 · p.49` ｜ 基础 ｜ **中性** ｜ 第三章 ｜ 英文：Candlestick construction

![图3.3 蜡烛线的画法](figures/fig3.3.png)

| 判读项 | 内容 |
|---|---|
| **结构判定** | 同一根蜡烛线记录四个价格：开市价、最高价、最低价、收市价。实体（矩形）连接开市价与收市价；上影线由实体上沿连至最高价，下影线由实体下沿连至最低价。收市高于开市为白色（阳线），收市低于开市为黑色（阴线）。 |
| **确认信号** | 实体长度=开收价差（当日多空净战果）；影线长度=该方向的试探与失败幅度。实体越长，方向性共识越强；实体越短，多空越僵持。 |
| **心理机制** | 线图只保留收市价一条轨迹，蜡烛图保留了盘中争夺的全过程。同一根K线里的上影线是「多头曾攻上去、被打回来」的物证，这在收盘线图上是看不见的。 |
| **失效条件** | 四个价格相同时（一字线）不含方向信息；流动性极差或停牌时开高低收失真，形态判定整体失效。 |
| **要点 / 陷阱** | 作者的核心主张：蜡烛图不是新指标，而是同一组价格数据的另一种编码——因此西方所有基于OHLC的工具都能直接叠加使用。 |

## 纺锤线（小实体线）

`图3.6 · p.53` ｜ 基础 ｜ **中性** ｜ 第三章 ｜ 英文：Spinning top

![图3.6 纺锤线（小实体线）](figures/fig3.6.png)

| 判读项 | 内容 |
|---|---|
| **结构判定** | 实体很小，上下影线都有一定长度，整体像一只纺锤。没有硬性比例阈值，通常实体长度小于当根K线总幅度的三分之一。 |
| **确认信号** | 纺锤线本身不是买卖信号，它的意义是「当前方向的驱动力在衰减」。作为形态组件时（星线、孕线、平头形态的第二根）才具备方向含义。 |
| **心理机制** | 开收价接近，说明多空在该时段内反复争夺后回到原点；出现位置越高（上涨末端）或越低（下跌末端），越说明原趋势的推动者已经无法维持单边控制。 |
| **失效条件** | 在横盘箱体中连续出现纺锤线不构成任何信号——没有可反转的趋势。日线级别单根纺锤线的信息量极低，必须与位置和其他信号合并解读。 |
| **要点 / 陷阱** | 作者的判读顺序：先看它长在什么趋势的什么位置，再看它组成了什么形态，最后才看它自身。 |

## 十字线（基础）

`图3.7 · p.54` ｜ 基础 ｜ **中性** ｜ 第三章 ｜ 英文：Doji

![图3.7 十字线（基础）](figures/fig3.7.png)

| 判读项 | 内容 |
|---|---|
| **结构判定** | 开市价与收市价处于同一水平（或仅差几个最小报价单位），实体退化为一条横线。上下影线可有可无、可长可短。 |
| **确认信号** | 十字线是「完全均衡」的极值形态：比纺锤线更彻底地表明多空打成平手。在上涨之后出现视为警告；在下跌之后出现需额外佐证才可视为底部信号。 |
| **心理机制** | 开盘价与收盘价相等意味着：整个时段的所有进攻最后都被完全抵消。趋势要延续，必须有一方持续占优；均衡状态本身就是趋势延续的反证。 |
| **失效条件** | 出现在箱体区间中部的十字线没有预测意义（无趋势可反转）；同一张图上十字线出现频率过高时，单根十字线的边际信息趋近于零。 |
| **要点 / 陷阱** | 作者的经验：宁可错认不可漏过——近似十字线（开收差几美分）在关键位置应按十字线对待。 |

# 二 · 反转形态

## 伞形线

`图4.4 · p.62` ｜ 反转 ｜ **双向** ｜ 第四章 ｜ 英文：Umbrella line

![图4.4 伞形线](figures/fig4.4.png)

| 判读项 | 内容 |
|---|---|
| **结构判定** | 下影线很长、实体很小、实体位于整个价格区间的顶端，上影线没有或极短。黑白实体皆可。 |
| **确认信号** | 伞形线本身是中性的，方向由它出现之前的趋势决定：跌势之后=锤子线（看涨），涨势之后=上吊线（看跌）。同一个形状，两种相反含义。 |
| **心理机制** | 长下影线记录了一次「盘中大幅下挫后被全部买回」的过程。在低位，这是空头最后一次成功的假突破；在高位，这是多头最后一次失败的冲锋。 |
| **失效条件** | 下影线不足实体两倍的「准伞形线」严格来说不成立，作者的处理是：不否认其提示价值，但不据此单独开仓。 |
| **要点 / 陷阱** | 这是全书第一个「形状相同、含义相反」的案例，也是蜡烛图技术最容易被误用的地方——脱离趋势谈形态，等于没有形态。 |

## 锤子线

`图4.5 · p.63` ｜ 反转 ｜ **看涨** ｜ 第四章 ｜ 英文：Hammer

![图4.5 锤子线](figures/fig4.5.png)

| 判读项 | 内容 |
|---|---|
| **结构判定** | 三条硬标准：①实体位于整个价格区间上端，颜色不限；②下影线长度至少为实体高度的两倍；③没有上影线，或极短。必须紧接在下跌行情之后出现。 |
| **确认信号** | 锤子线不需要等待验证信号即可视为潜在看涨信号（这是它与上吊线的关键区别）。实体为白色时看涨意味更硬（收市于最高价），日语称「力量线」；但作者实测成功率与实体颜色无关。 |
| **心理机制** | 当日先急跌，收市却回到最高价附近——空头在盘中一度完全掌控，收盘时却被全部击退（日本人称「神风反击」）。下影线越长、上影线越短、实体越小，信号越强。 |
| **失效条件** | 之前没有下跌趋势，锤子线不成立；下影线不够长（不足实体两倍）时只是「类似锤子」，需等次日验证。锤子线不提供价格目标，也不保证反转幅度。 |
| **要点 / 陷阱** | 锤子线的低点天然构成支撑位，可作为止损参考点。若在收市价追进，止损距离往往过大——作者建议等回落到下影线区间内再买，把建仓价压到止损位附近。 |

## 上吊线

`图4.6 · p.64` ｜ 反转 ｜ **看跌** ｜ 第四章 ｜ 英文：Hanging man

![图4.6 上吊线](figures/fig4.6.png)

| 判读项 | 内容 |
|---|---|
| **结构判定** | 形状与锤子线完全相同（小实体在上端、长下影线、无上影线），但必须紧接在上涨行情之后出现；作者额外要求：之前应有足够长足的上冲，最好是创出历史新高。 |
| **确认信号** | 必须等待验证：之后时段的收市价低于上吊线的实体（最低限度是开市价低于实体，作者更认可收市价标准）。未获验证的上吊线无效。 |
| **心理机制** | 在上吊线当日开市与收市买进的人（成交量最集中的两个时点）全部被「吊」在高位。次日收市跌破实体，这批新多头集体套牢，被迫平仓，卖压自我强化。 |
| **失效条件** | 只要市场没有收市于上吊线实体之下、并继续创新高，上升趋势就依然稳固——此时的上吊线是假警报（原书图4.12 用三根上吊线演示了这一点）。 |
| **要点 / 陷阱** | 上吊线是全书中「验证信号」概念的最佳教具：形态给出的是嫌疑，验证信号才是定罪。 |

## 看涨吞没形态（抱线）

`图4.13 · p.73` ｜ 反转 ｜ **看涨** ｜ 第四章 ｜ 英文：Bullish engulfing

![图4.13 看涨吞没形态（抱线）](figures/fig4.13.png)

| 判读项 | 内容 |
|---|---|
| **结构判定** | 三条标准：①之前必须处在明确的下降趋势中（哪怕只是短期）；②第二根实体完全覆盖第一根实体（不必吞没影线）；③第二根为白色、第一根为黑色。例外：第一根是十字线时，颜色条件可放宽。 |
| **确认信号** | 第二根实体收盘越坚挺（开于最低、收于最高）越强。增强要素：第一根实体极小（纺锤线）而第二根极大；出现在超长或极快的行情之后；第二根伴随超额成交量。 |
| **心理机制** | 空头原本掌控局面，次日却被打出一根反向的大实体，把前一日的全部战果吞掉——控制权在一天之内易手。这正是它在西方对应物「反转日」之上的增量：反转日只看收市价，吞没还要求实体覆盖。 |
| **失效条件** | 形态的完成必须等到第二根收市，此时价格往往已远离低点，风险报偿比可能已经恶化。突破失败（收市回到形态低点之下）即失效。 |
| **要点 / 陷阱** | 吞没形态的两个端点直接变成交易坐标：看涨吞没的最低点=支撑，看跌吞没的最高点=阻挡。这是把形态转成可执行价位的标准做法。 |

## 看跌吞没形态（抱线）

`图4.14 · p.73` ｜ 反转 ｜ **看跌** ｜ 第四章 ｜ 英文：Bearish engulfing

![图4.14 看跌吞没形态（抱线）](figures/fig4.14.png)

| 判读项 | 内容 |
|---|---|
| **结构判定** | ①之前处于明确上升趋势；②第二根黑色实体完全覆盖第一根白色实体；③颜色相反（第一根为十字线时例外）。 |
| **确认信号** | 黑色实体越长、收盘越贴近最低价，信号越强。若第二根未能创新高却仍完成吞没，蜡烛图依然有效——这一点是它优于西方「反转日」的地方（反转日要求创新高）。 |
| **心理机制** | 多头在盘中把价格推到新高，收盘却被一根更大的阴线全部吞回。所有在当日买入者当场浮亏，供给压倒需求。 |
| **失效条件** | 没有上升趋势作前提的「黑包白」只是普通阴线，不构成顶部反转（原书图5.9 A处专门辨析了这一点）。收市重新站上形态最高点即失效。 |
| **要点 / 陷阱** | 看跌吞没的最高点=阻挡位。若价格以收市价突破该阻挡，原看跌判断作废，反而构成看涨突破信号。 |

## 乌云盖顶形态

`图4.22 · p.84` ｜ 反转 ｜ **看跌** ｜ 第四章 ｜ 英文：Dark cloud cover

![图4.22 乌云盖顶形态](figures/fig4.22.png)

| 判读项 | 内容 |
|---|---|
| **结构判定** | ①出现在上升趋势之后（或水平整理区间的顶部）；②第一根是坚挺的白色实体；③第二根开市价高于第一根的最高价（跳过上影线顶端）；④第二根收市价明显扎入第一根白色实体内部。 |
| **确认信号** | 扎入越深越强，理想状态是收盘跌破第一根实体的中点（50%）。若未过中点，应等待进一步看跌验证。增强要素：第一根光头光脚、第二根光头光脚、第二根开盘突破主要阻挡后失守、次日开盘巨量（胀爆）。 |
| **心理机制** | 第二天跳空高开，多头以为突破在即；收盘却被打回前一日实体的深处，把当天的涨幅全部交还。追高者在最高点接货，止损盘由此被激活。 |
| **失效条件** | 第二根若完全覆盖第一根实体，性质升级为看跌吞没（信号更强）；若之后出现一根长白线且收市超过本形态最高点，则预示新一轮上冲，形态失效。 |
| **要点 / 陷阱** | 作者用日食作比喻：乌云盖顶是日偏食（遮住部分实体），看跌吞没是日全食（遮住全部实体）——遮得越多，顶部意义越大。 |

## 刺透形态

`图4.26 · p.90` ｜ 反转 ｜ **看涨** ｜ 第四章 ｜ 英文：Piercing pattern

![图4.26 刺透形态](figures/fig4.26.png)

| 判读项 | 内容 |
|---|---|
| **结构判定** | ①出现在下跌趋势中；②第一根为黑色实体；③第二根为白色实体，开市价向下跳空至第一根最低价之下（理想状态）；④收市价向上刺入第一根黑色实体，且必须超过其中点。 |
| **确认信号** | 「必须过中点」这一条没有灵活余地——这是它与乌云盖顶最大的不对称。作者的解释：日本人对底部形态的处理远比顶部严格，因为抄底的容错空间更小。 |
| **心理机制** | 第二天空头借跳空低开确认优势，收盘却被多头一路推回到前一日实体的上半部。空头当日的浮盈全部蒸发并转为浮亏，被迫回补。 |
| **失效条件** | 白线未过黑实体中点者，降级为待入线/切入线/插入线（见下三条），只能作为提示，必须等待次日验证。收市跌回形态最低点之下即失效。 |
| **要点 / 陷阱** | 刺透形态的最低点构成支撑位；若形态完成后价格已远离该支撑，等回落到该区域再介入，是控制风险的标准动作。 |

`图5.3 · p.102` ｜ 反转 ｜ **看涨** ｜ 第五章 ｜ 英文：Morning star

| 判读项 | 内容 |
|---|---|
| **结构判定** | 三根K线：①长黑实体（空头主宰）；②小实体，与前一根实体不接触（星线）；③白线，明显向上推进到第一根黑色实体之内。必须出现在下跌之后。 |
| **确认信号** | 决定性因素是：第二根应为纺锤线，且第三根应显著深入第一根黑色实体内部。第二、三根之间是否有跳空并非必要条件（有则更理想）。 |
| **心理机制** | 长黑→星线（空头力竭）→长白（多头夺回主导权）。三根K线完整记录了控制权从一方转移到另一方的全过程。作者比喻为「启明星预示太阳升起」。 |
| **失效条件** | 形态要到第三根收市才完成，此时价格往往已经急速反弹，追进的风险报偿比很差。若第三根收市未能深入第一根实体，形态降级。 |
| **要点 / 陷阱** | 形态最低点=支撑位。作者给出的实战解法：不在完成时追，而是等回落到该支撑区再分批建仓，把止损放在形态低点之下。 |

`图5.7 · p.107` ｜ 反转 ｜ **看跌** ｜ 第五章 ｜ 英文：Evening star

| 判读项 | 内容 |
|---|---|
| **结构判定** | ①长白实体；②星线（小实体，与第一根实体不重叠）；③长黑实体，剧烈向下扎入第一根白色实体内部。必须出现在上升趋势之后。 |
| **确认信号** | 关键在第三根黑线扎入第一根白实体的深度。第二与第三根之间的跳空可有可无（罕见，非必要条件）。增强要素：三根实体两两不重叠、第三根深深扎入、第一根量小而第三根量大。 |

## 孕线形态

`图6.1 · p.127` ｜ 反转 ｜ **双向** ｜ 第六章 ｜ 英文：Harami

![图6.1 孕线形态](figures/fig6.1.png)

| 判读项 | 内容 |
|---|---|
| **结构判定** | 两根K线：前一根为长实体（「母」），后一根实体很小且完全被前一根实体包含（「子/胎」）。第二根颜色不限，影线可以超出第一根的范围。 |
| **确认信号** | 第二根实体越小，形态越强。与吞没形态的顺序正好相反（吞没是「后大包前小」，孕线是「前大包后小」）。 |
| **心理机制** | 长实体显示原方向力量充沛，次日却缩成一个小实体——市场「上气不接下气」。推动力的骤降本身就是趋势可能转向的证据。 |
| **失效条件** | 孕线只要求实体包含，不要求高低点包含（这一点比西方「收缩日」宽松）；因此它的信号强度低于吞没，属于较弱反转。 |
| **要点 / 陷阱** | 作者称孕线的技术意义是「趋势可能变化」，而不是「必然反向」——它常对应趋势由单边转为横盘，而非直接掉头。 |

## 十字孕线形态（呆滞形态）

| 判读项 | 内容 |
|---|---|
| **结构判定** | 孕线的极端形式：第二根收缩为十字线（开=收），被前一根长实体完全包含。 |
| **确认信号** | 技术意义强于常规孕线，被视为更有效的反转信号。作者经验：它在市场顶部比在底部更有效力。 |

| **要点 / 陷阱** | 若在一根很长的白线之后出现十字孕线而无动于衷，作者的原话是：把自己推到了危险的境地。 |

|---|---|
| **结构判定** | 两根颜色相反的K线，收市价处于同一水平。看涨版：第一根长黑，第二根大幅跳空低开后反攻，收市回到前一日收市价。 |
| **确认信号** | 第二天的开市价必须强劲地跳空到低位（顺着原趋势前进了一大步），然后完全收复——这个「先顺后反」的落差是力量所在。收市价不必恰好相等，足够接近即可。 |
| **心理机制** | 空头在开盘时取得了趋势的最后一次确认，收盘却被完全抵消——「朝夕之间扭转了行情基调」。 |
| **失效条件** | 比刺透形态弱：它只回到前收市价，没有刺入前一日实体内部。若无其他佐证，不应视同刺透。 |
| **要点 / 陷阱** | 与刺透的区别一句话：刺透是「打进去」，反击线是「打回来」。 |

|---|---|
| **结构判定** | 第一根长白，第二根向上跳空高开后回落，收市价回到前一日收市价水平。 |
| **确认信号** | 与乌云盖顶同源但更弱：第二根收市未刺入白实体内部，只是回到起点。 |
| **心理机制** | 多头在开盘时以为突破在握，收盘被打回原点——所有当日追高者当场被套。 |
| **失效条件** | 若第二根收市跌破白实体中点，性质升级为乌云盖顶；若收市站上新高，形态失效。 |

# 三 · 持续形态

## 向上的窗口（向上跳空）

`图7.1 · p.192` ｜ 持续 ｜ **看涨** ｜ 第七章 ｜ 英文：Rising window

![图7.1 向上的窗口（向上跳空）](figures/fig7.1.png)

| 判读项 | 内容 |
|---|---|
| **结构判定** | 前一时段的最高点（上影线顶端）与本时段的最低点（下影线底端）之间存在价格真空——注意：必须是「影线之间」不重叠，实体之间的空白不算窗口。 |
| **确认信号** | 窗口是持续性信号：应顺着窗口方向建立头寸。窗口的全部空间构成支撑区域；只要收市价不低于窗口下缘，上升趋势就依然成立。 |
| **心理机制** | 价格在没有任何成交的真空区跳升，意味着卖方在该区间完全缺席。此后任何回落进入该真空，都会遇到「没有卖出意愿」的支撑。日本人的说法：「调整行情于窗口处终结。」 |
| **失效条件** | 收市价跌到窗口下缘之下，上升趋势不成立。窗口大小不重要（4美分也算），但幅度越大，支撑区域越宽、越难精确使用。 |
| **要点 / 陷阱** | 最常见的误用：把「实体之间有空隙但影线重叠」当成窗口。作者专门用图7.3 纠正了这一点。 |

## 向下的窗口（向下跳空）

`图7.2 · p.192` ｜ 持续 ｜ **看跌** ｜ 第七章 ｜ 英文：Falling window

![图7.2 向下的窗口（向下跳空）](figures/fig7.2.png)

| 判读项 | 内容 |
|---|---|
| **结构判定** | 前一时段最低点与本时段最高点之间存在价格缺口（影线不重叠）。 |
| **确认信号** | 看跌持续信号。此后任何反弹都会在该窗口处遭遇阻挡（整个窗口空间）。只有收市价推升到窗口上缘之上，下降趋势才告结束。 |
| **心理机制** | 跳空下跌留下无人成交的真空，反弹进入该区域时没有买盘承接（因为该区间的持仓成本为零），供给在此处集中释放。 |
| **失效条件** | 收市站上窗口上缘即失效。连续多个同向窗口时，以「最后一个窗口是否被关闭」作为趋势存续的判据。 |
| **要点 / 陷阱** | 作者修正了日本传统「三个窗口后趋势将尽」的说法：真正的判据是最后一个窗口是否被收市价关闭。 |

## 向上跳空并列阴阳线

`图7.10 · p.203` ｜ 持续 ｜ **看涨** ｜ 第七章 ｜ 英文：Upward gap side-by-side lines

![图7.10 向上跳空并列阴阳线](figures/fig7.10.png)

| 判读项 | 内容 |
|---|---|
| **结构判定** | 一根白线与一根黑线共同构成一个向上的窗口；黑线开市于前一根白实体之内，收市于其下。两根实体大小应不相上下。 |
| **确认信号** | 黑线的收市价是争夺要点；若收市跌破窗口，看涨意义不再成立。 |
| **心理机制** | 跳空后先阳后阴，看似转弱，实则窗口未被封闭——真空区仍在支撑。 |
| **失效条件** | 形态罕见。作者明言：不必费脑记忆，窗口才是关键，之后两根K线什么颜色并不重要。 |
| **要点 / 陷阱** | 这是全书「去神秘化」最明显的一节：形态名称是历史的包袱，窗口位置才是有效信息。 |

## 向下跳空并列阴阳线

`图7.11 · p.205` ｜ 持续 ｜ **看跌** ｜ 第七章 ｜ 英文：Downward gap side-by-side lines

![图7.11 向下跳空并列阴阳线](figures/fig7.11.png)

| 判读项 | 内容 |
|---|---|
| **结构判定** | 一根黑线与一根白线共同构成向下的窗口；白线开市于前一根黑实体之内，收市于其下（方向相反）。 |
| **确认信号** | 窗口构成阻挡。若收市站上窗口上缘，看跌意义消除。 |
| **心理机制** | 跳空后出现阳线，看似反抽，但价格仍在真空区之下——反弹没有改变供给结构。 |
| **失效条件** | 同样罕见，同样不必死记。判据仍是窗口。 |
| **要点 / 陷阱** | 作者的实战建议：把这两个形态当成「窗口」的注脚，而不是独立的交易规则。 |

## 高价位跳空突破形态

`图7.13 · p.206` ｜ 持续 ｜ **看涨** ｜ 第七章 ｜ 英文：High-price gapping play

![图7.13 高价位跳空突破形态](figures/fig7.13.png)

| 判读项 | 内容 |
|---|---|
| **结构判定** | 上升趋势中：一根坚挺K线之后出现一群小实体（横向整理、消化超买），随后某日从这群小实体向上打开一个窗口。 |
| **确认信号** | 窗口出现即构成看涨信号。一旦收市价跌回该窗口之下，形态的看涨意义消除。 |
| **心理机制** | 小实体群完成了「踩水」——把超买状态缓解掉；随后跳空突破，说明整理结束、买方重新掌控。作者称这种整理是「健康的」。 |
| **失效条件** | 若整理后向下跳空（而非向上），性质转为低价位跳空突破的反向情形。 |
| **要点 / 陷阱** | 这个形态把「整理」从噪声变成了结构的一部分：整理的位置和幅度决定了突破的有效性。 |

## 低价位跳空突破形态

`图7.14 · p.207` ｜ 持续 ｜ **看跌** ｜ 第七章 ｜ 英文：Low-price gapping play

| 判读项 | 内容 |
|---|---|
| **结构判定** | 急剧下跌后出现一群小实体（看似在构筑底部），随后从该密集区向下打开一个窗口。 |
| **确认信号** | 窗口出现即确认看跌。 |
| **心理机制** | 小实体群让市场以为底部正在形成，随后的向下跳空打破了这个期望——多头预期落空，止损盘涌出。 |
| **失效条件** | 若随后收市站上窗口上缘，看跌意义消除。 |
| **要点 / 陷阱** | 与高价位版本完全对称。两者共同的判别点：整理是「中继」还是「反转」，由跳空方向裁决。 |

## 上升三法形态

`图7.21 · p.214` ｜ 持续 ｜ **看涨** ｜ 第七章 ｜ 英文：Rising three methods

![图7.21 上升三法形态](figures/fig7.21.png)

| 判读项 | 内容 |
|---|---|
| **结构判定** | ①一根长白；②随后 2~5 根依次下降或横向的小实体，全部局限在第一根K线的最高价与最低价范围之内（含影线）；③最后一根坚挺白线，收市高于第一根收市价，开市高于前一日收市价。 |
| **确认信号** | 小实体理想为 3 根、以黑色居多，但 2 根或更多、任意颜色均可接受。最后一根白线若伴随最大成交量，验证力最强。 |
| **心理机制** | 长白确立方向 → 小实体群是「喘息」而非反转 → 长白恢复。日本人的说法：三法代表买卖之外的第三种状态——休息。 |
| **失效条件** | 若小实体越出第一根K线的全幅范围，形态不成立（原书图7.24 区域A 即因出现长实体3 而被排除）。形态完成时价格往往已远离低点，追进的风险报偿比差。 |
| **要点 / 陷阱** | 形态常出现在阻挡位附近——此时它是「看涨信号但位于阻力下方」，不构成有效买点。位置优先于形态。 |

## 分手线形态

`图7.31 · p.225` ｜ 持续 ｜ **双向** ｜ 第七章 ｜ 英文：Separating lines

![图7.31 分手线形态](figures/fig7.31.png)

| 判读项 | 内容 |
|---|---|
| **结构判定** | 两根颜色相反的K线，但开市价处于同一水平（与反击线的「收市价相同」正好相对）。看涨版：黑线之后白线开在同一开市价并收高；看跌版方向相反。 |
| **确认信号** | 看涨分手线中的白线应同时是一根看涨捉腰带线（开于最低、收于最高）。属持续信号，不是反转。 |
| **心理机制** | 上涨途中出现一根黑线，多头心生疑虑；次日开市直接回到前一日开市价，等于宣告空头一日游结束——「分手」即从此处分道扬镳。 |

## 十字线（专章）

`图8.1 · p.230` ｜ 十字线 ｜ **双向** ｜ 第八章 ｜ 英文：Doji

![图8.1 十字线（专章）](figures/fig8.1.png)

| 判读项 | 内容 |
|---|---|
| **结构判定** | 开市价与收市价处于同一水平（允许几个最小报价单位的误差）。 |
| **确认信号** | 三条增强条件：①后续K线验证；②市场处于超买或超卖状态；③该市场极少出现十字线（若满图都是十字线，新增一根毫无意义）。 |
| **心理机制** | 完全均衡。在上涨中，买方的犹豫直接瓦解了上涨所需的「坚定立场」；在下跌中，均衡反而可能只是「因为自身重力而下坠」的中继。 |
| **失效条件** | 十字线揭示顶部远比揭示底部有效。下降趋势中的十字线（南方十字线）常丧失反转潜力，需要更多佐证。 |
| **要点 / 陷阱** | 作者的处置纪律：出现十字线，把短期趋势从「上升」调为「上升或中性」；只有与另一技术信号验证时，才调为「中性或下降」。 |

## 长腿十字线（黄包车夫线）

`图8.2 · p.231` ｜ 十字线 ｜ **中性** ｜ 第八章 ｜ 英文：Long-legged doji

![图8.2 长腿十字线（黄包车夫线）](figures/fig8.2.png)

| 判读项 | 内容 |
|---|---|
| **结构判定** | 同时具备长长的上影线与长长的下影线，且实体收缩为十字线（若为小实体则称「大风大浪线」）。 |
| **确认信号** | 代表市场「失去了方向感」：先猛烈上推、再急剧下滑、又强烈反弹，收市回到原点。 |
| **心理机制** | 盘中双向都曾大幅推进，最终全部回吐——这是混乱而非均衡，意味着此前的趋势已经无法主导价格。 |
| **失效条件** | 在箱体中部的长腿十字线无预测意义；连续出现时信息量递减。 |
| **要点 / 陷阱** | 大风大浪线（长上下影+小实体）与长腿十字线只差「有无实体」，但前者是「混乱」，后者是「彻底失向」。 |

## 墓碑十字线（灵位十字线）

`图8.3 · p.232` ｜ 十字线 ｜ **看跌** ｜ 第八章 ｜ 英文：Gravestone doji

![图8.3 墓碑十字线（灵位十字线）](figures/fig8.3.png)

| 判读项 | 内容 |
|---|---|
| **结构判定** | 开市价与收市价都位于当日最低点，上影线很长，无下影线。 |
| **确认信号** | 流星线的极致版本（流星有小实体，墓碑没有实体）。昭示市场顶部的能力最强。 |
| **心理机制** | 全天曾大幅上冲，收盘却跌回最低——多头为捍卫阵地「战死」，故得名。视觉上无需解释即可读出看跌。 |
| **失效条件** | 不预测下跌幅度。若收市仍高于此前的关键阻挡/支撑，需等下一时段收市跌破该水平才确认（原书图8.11 的处理）。 |
| **要点 / 陷阱** | 作者提醒：不要把「墓碑」误读为「即将暴跌」，它只说明「向上突破失败」，不说明会跌多少。 |

## 北方十字线与南方十字线

`图8.6 · p.235` ｜ 十字线 ｜ **双向** ｜ 第八章 ｜ 英文：Northern / Southern doji

| 判读项 | 内容 |
|---|---|
| **结构判定** | 作者自创的区分：上涨行情中的十字线为北方十字线（看跌倾向），下降行情中的十字线为南方十字线（看涨倾向，但可靠性低得多）。 |
| **确认信号** | 北方十字线：警惕顶部。南方十字线：除非验证了支撑，否则一般不构成底部信号。 |
| **心理机制** | 市场「因自身重力下坠」——向下突破不需要买盘配合，向上突破必须有买盘推动。因此均衡状态在下跌中更容易被向下打破。 |
| **失效条件** | 南方十字线是全书被反复警告的陷阱：原书图8.15 中 A 到 F 连续六根十字线，全部未能构成底部反转。 |

## 箱体区间中的十字线

`图8.13 · p.244` ｜ 十字线 ｜ **中性** ｜ 第八章 ｜ 英文：Doji in a trading range

| 判读项 | 内容 |
|---|---|
| **结构判定** | 十字线出现在横向交易区间（「箱体」）的中部。 |
| **确认信号** | 无预测意义——因为没有可反转的趋势。例外：十字线位于箱体的顶部或底部时，可用于验证阻挡或支撑。 |
| **心理机制** | 箱体中部本身就是均衡区，十字线只是把宏观的均衡在微观上复述了一遍，不提供新增信息。 |
| **失效条件** | 把这个十字线当反转信号，是最常见的误判之一。 |
| **要点 / 陷阱** | 判读顺序永远是：先问「有没有趋势可以反转」，再问「这是什么形态」。 |

## 岛形顶部反转形态（西方对照）

`图5.8 · p.108` ｜ 西方工具 ｜ **看跌** ｜ 第五章 ｜ 英文：Island top reversal

![图5.8 岛形顶部反转形态（西方对照）](figures/fig5.8.png)

| 判读项 | 内容 |
|---|---|
| **结构判定** | 交易时段2的最低点必须同时高于时段1和时段3的最高点——即中间一段被两次跳空完全隔离成「孤岛」。 |
| **确认信号** | 与黄昏星的差别：黄昏星只要求「实体2的低点高于实体1的高点」，岛形顶要求「时段2的最低点高于时段1和3的最高点」（含影线）。 |
| **心理机制** | 价格跳空上去、停留、再跳空下来，中间留下一个完全没有成交重叠的孤岛。孤岛上的所有持仓成本被完全隔离，反转一旦发生便无支撑可依。 |
| **失效条件** | 要求严格，出现频率远低于黄昏星；在跳空频繁的市场中极易误判。 |
| **要点 / 陷阱** | 这一对比较是全书方法论的缩影：日本形态用「实体」判定（更灵敏、更多信号），西方形态用「全幅」判定（更严格、更少伪信号）。 |

## 上升（向上倾斜）的支撑线

`图11.1 · p.268` ｜ 西方工具 ｜ **看涨** ｜ 第十一章 ｜ 英文：Upward sloping support line

![图11.1 上升（向上倾斜）的支撑线](figures/fig11.1.png)

| 判读项 | 内容 |
|---|---|
| **结构判定** | 连接至少两个向上反弹的低点（蜡烛图上取下影线的低点），三个或更多更好。 |
| **确认信号** | 支撑线代表买方比卖方更积极：在逐步抬高的低点上仍能吸引新需求。 |
| **心理机制** | 每一轮回调都在更高的位置被买回，说明持有成本在抬升、卖方愿意接受的价格在提高。 |
| **失效条件** | 被收市价有效跌破即失效；跌破后按极性转换原则转为阻挡。 |
| **要点 / 陷阱** | 作者的用词很讲究：不是「买方多于卖方」（每笔交易必然一对一），而是「买方更积极进取」。 |

## 下降（向下倾斜）的支撑线

`图11.2 · p.268` ｜ 西方工具 ｜ **中性** ｜ 第十一章 ｜ 英文：Downward sloping support line

![图11.2 下降（向下倾斜）的支撑线](figures/fig11.2.png)

| 判读项 | 内容 |
|---|---|
| **结构判定** | 连接越来越低的低点所形成的向下倾斜直线。 |
| **确认信号** | 在缺乏其他支撑线索时（尤其是市场正在创历史新低、上方没有可参照的低点时）提供潜在的支撑区域。 |
| **心理机制** | 虽然低点在下移，但每次触及该线都能引发反弹，说明这条「动态支撑」仍在起作用。 |
| **失效条件** | 因其向下倾斜，由此引发的反弹通常是有限且不持久的；只宜作为「考虑买进的区域」，不宜作为趋势反转的依据。 |
| **要点 / 陷阱** | 这是最容易被忽略的一种趋势线：常规支撑线连接抬高的低点，而下降支撑线连接降低的低点——两者都能提供支撑，但含义不同。 |

## 下降的阻挡线

`图11.6 · p.271` ｜ 西方工具 ｜ **看跌** ｜ 第十一章 ｜ 英文：Downward sloping resistance line

![图11.6 下降的阻挡线](figures/fig11.6.png)

| 判读项 | 内容 |
|---|---|
| **结构判定** | 连接至少两个向下反弹的高点（蜡烛图上取上影线的顶点）。 |
| **确认信号** | 代表卖方比买方更积极：在逐步降低的高点上仍愿意卖出。反映市场处于下降趋势。 |
| **心理机制** | 每一次反弹都在更低的位置被卖回，说明供给方愿意不断降价出货。 |
| **失效条件** | 被收市价向上突破即失效，并按极性转换转为支撑。 |

## 上升的阻挡线

`图11.7 · p.272` ｜ 西方工具 ｜ **看跌** ｜ 第十一章 ｜ 英文：Upward sloping resistance line

![图11.7 上升的阻挡线](figures/fig11.7.png)

| 判读项 | 内容 |
|---|---|
| **结构判定** | 连接一系列更高的高点所形成的向上倾斜直线。 |
| **确认信号** | 用于市场处在历史新高、上方没有更早的高点可连接的情形——这是它存在的理由。 |
| **心理机制** | 价格沿着一条向上倾斜的「天花板」运行：每次创新高都刚好触线回落，说明供给在按固定斜率上移。 |
| **失效条件** | 一旦被收市价突破，该线失效并可能转为支撑。 |
| **要点 / 陷阱** | 在牛市末期，这条线往往就是最后的离场参考——它把「还能涨多少」变成了一个可测量的几何问题。 |

## 破低反涨形态

`图11.11 · p.276` ｜ 西方工具 ｜ **看涨** ｜ 第十一章 ｜ 英文：Spring / false breakdown

![图11.11 破低反涨形态](figures/fig11.11.png)

| 判读项 | 内容 |
|---|---|
| **结构判定** | 在横向区间的支撑处：价格先向下跌破支撑，随后又回升到被跌破的支撑之上（新低无法维持）。 |
| **确认信号** | 可在单一时段内完成，也可跨数个时段完成。若向下突破时成交量轻、回升时成交量大，看涨意义显著增强。 |
| **心理机制** | 空头向下突破后无法守住新低，等于把「滩头阵地」丢掉了。所有在破位时卖出的人当场被套，回补买盘推动价格上行。作者引用拿破仑：最好的军队是「获胜的军队」。 |
| **失效条件** | 止损位设在最近的低点（最好以收市价为准）；若价格重新跌回该低点之下，形态失效。 |
| **要点 / 陷阱** | 价格目标有两个选择：形态出现前的行情高点，或此前横向区间的顶边。作者建议先取保守目标，再考虑激进目标。 |

## 破高反跌形态

`图11.12 · p.276` ｜ 西方工具 ｜ **看跌** ｜ 第十一章 ｜ 英文：Upthrust / false breakout

![图11.12 破高反跌形态](figures/fig11.12.png)

| 判读项 | 内容 |
|---|---|
| **结构判定** | 在横向区间的阻挡处：价格先向上突破阻挡，但多方无力维持新高，随后回落到被突破的阻挡之下。 |
| **确认信号** | 本质是「假突破」的另一种说法。若向上突破时量轻、回落时量重，成功率显著提高。 |
| **心理机制** | 多头派出「侦察兵」越过阻力线，却未能在敌占区扎营（收市价无法连续站稳），只好撤退；撤退过程中此前的追高者成为卖压。 |
| **失效条件** | 止损位设在最近的高点；若收市重新站上该高点，形态失效。 |
| **要点 / 陷阱** | 目标位 = 前一个低点，或横向区间的底边。作者提醒：这个技巧不需要清晰定义的阻挡线也能使用。 |

## 极性转换：支撑变阻挡

`图11.18 · p.284` ｜ 西方工具 ｜ **看跌** ｜ 第十一章 ｜ 英文：Polarity principle (support → resistance)

![图11.18 极性转换：支撑变阻挡](figures/fig11.18.png)

| 判读项 | 内容 |
|---|---|
| **结构判定** | 一个曾经被反复验证的支撑水平被向下突破后，该水平转为新的阻挡水平。 |
| **确认信号** | 需要该水平此前经历过数次验证（越多次验证，转换越可靠）。 |
| **心理机制** | 所有在该支撑区买入的人现在全部亏损，他们「一心祈祷市场回到盈亏平衡点」。一旦价格反弹回该区域，这批人争相解套卖出，支撑就变成了供给。作者的关键洞察：图表上最重要的价格，是你建仓的那个价格。 |
| **失效条件** | 若价格以收市价重新站上该水平，转换失效，市场重回原有格局。 |
| **要点 / 陷阱** | 全书反复出现、复用率最高的一个概念。它把「历史价位」变成了「未来的交易坐标」。 |

## 极性转换：阻挡变支撑

`图11.19 · p.284` ｜ 西方工具 ｜ **看涨** ｜ 第十一章 ｜ 英文：Polarity principle (resistance → support)

![图11.19 极性转换：阻挡变支撑](figures/fig11.19.png)

| 判读项 | 内容 |
|---|---|
| **结构判定** | 一个曾经被反复验证的阻挡水平被向上突破后，该水平转为新的支撑水平。 |
| **确认信号** | 同样要求此前的多次验证。突破需以收市价确认。 |
| **心理机制** | 此前在该阻力位做空、或在突破时追多的人，成本都集中在这一带；价格回落到此处时，前者回补、后者加仓，形成支撑。 |
| **失效条件** | 收市跌回该水平之下即失效。 |
| **要点 / 陷阱** | 与蜡烛图结合时最有效：当价格回落到「转换后的支撑」并且出现锤子线/看涨吞没，双重验证成立。 |

## 上升趋势中的百分比回撤

`图12.1 · p.292` ｜ 西方工具 ｜ **看涨** ｜ 第十二章 ｜ 英文：Fibonacci retracement in an uptrend

| 判读项 | 内容 |
|---|---|
| **结构判定** | 常用回撤比例：50%、38.2%、61.8%。从波段高点向下测量。 |
| **确认信号** | 作者的核心纪律：不在回撤位直接买卖，必须等到该位置出现蜡烛图信号验证。 |
| **心理机制** | 回撤位之所以有效，是因为大量交易者（江恩、艾略特、道氏的信奉者）都在用同一组比例，形成了自我实现的订单聚集区。 |
| **失效条件** | 单独使用回撤位胜率很低；不同市场、不同波段的最有效比例并不一致。 |
| **要点 / 陷阱** | 50% 是最受关注的一档，因为三大流派（江恩、艾略特、道氏）都用它。 |

## 下降趋势中的百分比回撤

`图12.2 · p.293` ｜ 西方工具 ｜ **看跌** ｜ 第十二章 ｜ 英文：Fibonacci retracement in a downtrend

![图12.2 下降趋势中的百分比回撤](figures/fig12.2.png)

| 判读项 | 内容 |
|---|---|
| **结构判定** | 从波段低点向上测量 38.2% / 50% / 61.8% 的反弹幅度。 |
| **确认信号** | 反弹到达回撤位并出现看跌蜡烛图信号（乌云盖顶、看跌吞没、流星）时，才是做空时机。 |
| **心理机制** | 下跌途中的反弹会在这些比例处遭遇此前套牢盘的解套抛压。 |
| **失效条件** | 强趋势中的反弹常越过 61.8%，甚至直接创新高——此时回撤框架失效。 |
| **要点 / 陷阱** | 回撤位+极性转换+长影线三者汇聚时，是全书最强调的「相互验证」范例（原书图12.4）。 |

## 箱体区间的突破信号

`图16.1 · p.337` ｜ 西方工具 ｜ **双向** ｜ 第十六章 ｜ 英文：Box / trading range breakout

![图16.1 箱体区间的突破信号](figures/fig16.1.png)

| 判读项 | 内容 |
|---|---|
| **结构判定** | 市场在横向区间内波动（日本称「箱体」）。向上突破箱顶为看涨，向下跌破箱底为看跌。 |
| **确认信号** | 价格目标 = 箱体的垂直高度，从突破点起算。例：50–53 美元的箱体，向上突破目标 56，向下突破目标 47。 |
| **心理机制** | 横向区间是能量的积蓄（压缩的弹簧）。突破时释放的能量，通常足以推动价格走出与箱体高度相当的幅度。 |
| **失效条件** | 价格目标不等于支撑/阻挡——行情可能越过目标继续走，也可能根本到不了。作者明确：不依价格目标开新仓，只用它平旧仓。 |
| **要点 / 陷阱** | 箱体突破 + 极性转换是一对组合拳：突破后原箱顶变支撑、原箱底变阻挡，这给了回抽时的入场依据。 |

## 对等运动的价格目标

`图16.6 · p.343` ｜ 西方工具 ｜ **双向** ｜ 第十六章 ｜ 英文：Measured move

![图16.6 对等运动的价格目标](figures/fig16.6.png)

| 判读项 | 内容 |
|---|---|
| **结构判定** | 三段结构：①一轮轮廓清晰的快速运动（A→B）；②调整（回落至 C）；③恢复原方向（第二波）。 |
| **确认信号** | 价格目标 = 第一波高度（A→B）叠加到调整低点 C 上。 |
| **心理机制** | 第一波确立了市场的「运动惯性」，调整只是换手；第二波在力度上通常不弱于第一波。 |
| **失效条件** | 若第二波明显短于第一波（力度衰减），说明趋势在减弱，目标不应机械套用。 |
| **要点 / 陷阱** | 对等运动与旗形/尖旗形共用同一套测算逻辑，区别只在于调整的形态与深度。 |

## 看涨的旗形与尖旗形

`图16.7 · p.343` ｜ 西方工具 ｜ **看涨** ｜ 第十六章 ｜ 英文：Bull flag / pennant

![图16.7 看涨的旗形与尖旗形](figures/fig16.7.png)

| 判读项 | 内容 |
|---|---|
| **结构判定** | 急速上涨（旗杆）→ 横向或略向下的密集区（旗形为箱体，尖旗形为收敛三角形）→ 恢复上涨。 |
| **确认信号** | 目标 = 旗杆高度（A→B）加到密集区的底边（作者的保守算法；传统做法是加到顶边）。 |
| **心理机制** | 密集区消化了超买状态，使后续上涨不必背负「获利盘随时兑现」的压力。 |
| **失效条件** | 若密集区向下跌破，形态转为反转而非持续。 |
| **要点 / 陷阱** | 作者主动选择更保守的算法：「我宁愿错在过早平仓，也不愿错在精确追求最后那一哆嗦行情。」 |

## 上升三角形与下降三角形

`图16.12 · p.348` ｜ 西方工具 ｜ **双向** ｜ 第十六章 ｜ 英文：Ascending / descending triangle

![图16.12 上升三角形与下降三角形](figures/fig16.12.png)

| 判读项 | 内容 |
|---|---|
| **结构判定** | 上升三角形：水平阻挡线 + 依次抬高的低点。下降三角形：水平支撑线 + 依次降低的高点。 |
| **确认信号** | 目标 = 三角形最宽处的垂直高度，从被突破的水平边起算。 |
| **心理机制** | 上升三角形：阻力固定而买盘成本不断抬高，说明需求在增强，突破概率偏大。下降三角形相反：支撑固定而卖压不断下压，破位概率偏大。 |
| **失效条件** | 三角形也可能在末端之前就失败（假突破），必须等收市价确认。 |
| **要点 / 陷阱** | 下降三角形破位后，原支撑（如 137）按极性转换成为阻挡——作者用图16.13 演示了这个双重验证。 |
