### 模型1：职业化投机模型（三条禁令与交易法则）

#### 1. 核心定义
把投机当职业，以三条禁令与一套交易法则约束行为：不摊薄亏损、不固执于臆测价位、不进场太早或离场太晚。

#### 2. 原理机制
三条禁令对应三种最典型的亏损机制。摊平把可控的小错变成不可控的大错；固执于臆测价位使人无视市场给出的相反证据；抢跑与恋战则使交易者在趋势未确认时入场、在趋势已反转时不肯离场。江恩的解法不是提高判断力，而是用禁令直接切断这些行为路径，再用交易法则给出替代动作。

#### 模型公式

```
禁令①: 不摊薄每股平均亏损额
禁令②: 不固执于臆测价位
禁令③: 不进场太早、不离场太晚
替代: 止损 + 顺势 + 按信号行动
```

#### 3. 适用场景与失效边界

| 维度 | 具体表述 |
|---|---|
| 常态规律 | 三条禁令**通常**能消除大部分致命错误。 |
| 环境要求 | **在**可挂止损单的市场**条件下**可执行。 |
| 失效条件 | 无法挂条件单时，禁令执行依赖自律，**失效**风险上升。 |
| 不适用场景 | 长线价值投资**不适用**短线禁令框架。 |

#### 4. 避坑警示
三条禁令里最难守的是第二条——人总愿意相信自己昨晚算出来的价位。

#### 5. 跨场景应用示例
- **健康管理**：不因一次破戒而放弃整个计划（不摊平）、不迷信某个偏方（不固执）、不等到病重才就医（不抢跑）。

### 模型2：总市值与相对强弱模型（总量定方向，强弱定标的）

#### 1. 核心定义
以全市场与各板块的总市值图判断资金流向，以个股相对大盘的强弱排名筛选标的。

#### 2. 原理机制
总市值等于全部上市公司股价乘以股本之和，它反映的是资金总量而非少数权重股的涨跌，因此比指数更难被扭曲。当总市值持续上升，说明增量资金在进场；当总市值上升而指数滞涨，说明资金在向中小盘扩散。相对强弱则回答「买什么」：在市场下跌时抗跌、在市场企稳时率先突破的个股，是资金真正的去处。

#### 模型公式

```
大势: 总市值趋势方向
轮动: 板块总市值相对变化
选股: 相对强弱排名（抗跌 + 率先突破）
对冲: 多最强 + 空最弱
```

#### 3. 适用场景与失效边界

| 维度 | 具体表述 |
|---|---|
| 常态规律 | 总市值趋势**通常**领先于指数拐点。 |
| 环境要求 | **在**成分稳定、股本变动可查**条件下**总市值可比。 |
| 失效条件 | 大规模增发或回购使股本剧变时，总市值**失效**。 |
| 不适用场景 | 成分股极少的板块**不适用**总市值判断。 |

#### 4. 避坑警示
把总市值上升简单等同于「牛市来了」，忽略了它也可能来自大规模增发。

#### 5. 跨场景应用示例
- **行业分析**：用行业总营收而非单家公司营收判断行业景气，避免样本偏差。

### 模型3：时间周期模型（从顶底起算的关键节点）

#### 1. 核心定义
从重要顶底起算，记录第 30、60、90、120、135、180、225、270、315、360 天（周、月）等节点，观察趋势是否变化。

#### 2. 原理机制
时间是推动力耗尽的过程。行情启动后，随着时间推移，追随者的边际买盘逐渐减少；当时间到达历史常见节点而价格无法创新高，说明买方已无力维持节奏。江恩用固定的节点序列把这些时刻标定出来，使「该警惕了」从感觉变成日历上的具体日期。

#### 模型公式

```
节点: 30/60/90/120/135/180/225/270/315/360
判据: 时间到 + 价未创新高 → 转折候选
确认: 配合角度线跌破或三日图转向
```

#### 3. 适用场景与失效边界

| 维度 | 具体表述 |
|---|---|
| 常态规律 | 关键节点**通常**对应波动率放大。 |
| 环境要求 | **在**历史数据连续**条件下**节点才可标定。 |
| 失效条件 | 长期停牌或制度断裂使时间轴失真时**失效**。 |
| 不适用场景 | 上市不足一年的新股**不适用**。 |

#### 4. 避坑警示
把节点当精确日期，会在提前或延后几天时全盘否定方法。节点只提示窗口。

#### 5. 跨场景应用示例
- **项目周期**：以里程碑天数而非日期管理进度，容许合理浮动。

### 模型4：角度线与正方图模型（把时间与价格放进同一坐标）

#### 1. 核心定义
以 45° 线为平衡线，2×1、4×1、8×1 为强势档位，其熊市对应线为弱势档位；以 12×12 与 9 的正方图读出阻力与转折。

#### 2. 原理机制
角度线把「涨得多快」转化为可比较的斜率，使趋势强弱成为可排序的档位；跌破一条即跌向更低一条，转弱因此成为渐进可观测的过程。正方图则把价格与时间量化到固定网格，当价格与时间在网格上同时到位，即构成转折候选。二者的共同逻辑是：时间与价格必须同时考虑，单看价格会误判。

#### 模型公式

```
强弱: 8×1 > 4×1 > 2×1 > 45°
熊市: 45° > 2×1 > 4×1 > 8×1
正方: 12×12 = 144；9 的正方 = 81
转折: 价格与时间同时在网格到位
```

#### 3. 适用场景与失效边界

| 维度 | 具体表述 |
|---|---|
| 常态规律 | 45° 线**通常**提供有效的动态支撑。 |
| 环境要求 | **在**图表刻度统一、时间轴连续**条件下**角度才准确。 |
| 失效条件 | 图表比例被拉伸时角度**失效**。 |
| 不适用场景 | 无连续时间轴的点阵图**不适用**。 |

#### 4. 避坑警示
在错误起点画角度线，是最常见的误用。必须从极限顶底或「0」位起算。

#### 5. 跨场景应用示例
- **增长分析**：以「每季度增长多少」的斜率而非总额判断趋势强弱。

### 模型5：隔夜图机械交易模型（收盘决策，次日执行）

#### 1. 核心定义
只记录收盘价与次日开盘价的关系，据此在收盘后决定次日买卖，把决策完全移出盘中。

#### 2. 原理机制
盘中价格受情绪、消息与流动性扰动，决策质量最低；收盘价则是一天博弈的最终结果，信息含量最高。隔夜图法用「收盘价相对前一日区间的位置」作为唯一信号，把复杂的盘中判断压缩为一个二元选择，从而使执行可复现、可复盘、可交给他人执行。江恩为美国钢铁给出的完整规则还包含加仓与止损的联动：信号连续同向时按固定间隔加仓，一旦反向信号出现则全部平仓并反手，使整套动作成为一个闭环状态机。

#### 模型公式

```
信号: 收盘 > 前日区间上沿 → 次日买
收盘 < 前日区间下沿 → 次日卖
止损: 反向边界外
执行: 开盘市价
```

#### 3. 适用场景与失效边界

| 维度 | 具体表述 |
|---|---|
| 常态规律 | 隔夜图**通常**在趋势明朗时最有效。 |
| 环境要求 | **在**可稳定取得收盘与开盘价**条件下**可执行。 |
| 失效条件 | 频繁跳空或停牌使区间失真时**失效**。 |
| 不适用场景 | 24 小时连续交易品种**不适用**该框架。 |

#### 4. 避坑警示
隔夜图的前提是严格执行，一旦盘中临时改单，方法即失效。

#### 5. 跨场景应用示例
- **运营决策**：把决策点固定在每日固定时段，避免被实时数据牵着走。

### 模型6：季节性节奏模型（年度节律与背景概率）

#### 1. 核心定义
不同月份的市场节奏存在系统性差异，某些月份更易形成顶部，某些月份更易形成底部；季节性只作背景概率，不替代价格判据。

#### 2. 原理机制
季节性来自资金与实体的年度节律：年初的资金配置、年中的结算压力、年末的税收与报表效应，都会周期性改变供求。江恩统计了历年的月度高低点分布，发现某些月份反复出现转折。但他明确：季节性只调整概率权重，不构成独立信号。

#### 模型公式

```
季节性 = 背景概率权重
用法: 在季节性高发月份收紧止损
禁用: 仅凭季节入场
```

#### 3. 适用场景与失效边界

| 维度 | 具体表述 |
|---|---|
| 常态规律 | 季节性**通常**在成熟市场更稳定。 |
| 环境要求 | **在**有长期月度数据**条件下**可统计。 |
| 失效条件 | 市场制度或结算规则改变后，季节规律**失效**。 |
| 不适用场景 | 新兴市场早期**不适用**季节统计。 |

#### 4. 避坑警示
把季节性当买卖信号，是最典型的「统计误用」。

#### 5. 跨场景应用示例
- **零售运营**：季节性与节假日效应只调整备货权重，不替代需求预测。
