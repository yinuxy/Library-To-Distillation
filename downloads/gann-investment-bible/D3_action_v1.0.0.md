### 模块一：江恩体系标准化作业程序（SOP）

#### 步骤1：定大势（第1章·总市值）

1. 绘制全市场与主要板块总市值图。
2. 判断总市值趋势方向与板块轮动。
3. 总市值向下时只做空或空仓。
4. 每周复核总市值与指数的背离。

#### 步骤2：选个股（第1章·股票何时走势最强）

1. 统计大盘下跌时抗跌、企稳时率先突破的个股。
2. 标记滞涨、回调即破位的弱势股。
3. 构建多最强、空最弱的对冲组合。
4. 剔除低价且无成长性的标的。

#### 步骤3：定窗口（第2章·预测股市行情的时间周期法则）

1. 从最近重要顶底起算天数。
2. 比对 30/60/90/120/135/180/225/270/315/360 节点。
3. 节点前后收紧止损。
4. 节点前后避免新开重仓。

#### 步骤4：定位置（第2章·如何运用平面几何中的角）

1. 从极限顶底绘制 45° 线及 2×1、4×1、8×1。
2. 在正方图上标出阻力位。
3. 记录价格当前所处的角度档位。

#### 步骤5：机械执行（第3章·隔夜图交易法）

1. 收盘后按隔夜图规则确定次日方向。
2. 开盘市价执行，止损设于反向边界外。
3. 盘中不改单。

### 适用边界与失效条件

| 维度 | 具体表述 |
|---|---|
| 常态规律 | 四级图表与总市值图**通常**在成熟市场中最有效。 |
| 环境要求 | **在**价格连续、成分稳定**条件下**历史阻力位才可比。 |
| 失效条件 | 指数成分大幅调整或制度断裂时，历史位**失效**。 |
| 不适用场景 | 流动性极差、单笔即可影响价格的小盘股**不适用**。 |
| 适用范围 | 隔夜图法**仅适用**于可稳定取得收盘与开盘价的市场。 |
