### 模型1：三图分工模型（月线定方向、周线定波段、日线定时机）

#### 1. 核心定义
用月、周、日三级图表分别承担方向、波段与时机三类决策，层级分明、互不越权。

#### 2. 原理机制
不同尺度记录不同量级的供求博弈。月线过滤日内噪音，只保留大资金建仓痕迹；周线呈现波段节奏与止损位；日线提供入场时机。用日线判方向会把回调误读为反转；用月线找买点则永远错过窗口。

#### 模型公式

```
方向=月线顶底序列
节奏=周线回调幅度
时机=日线企稳或突破
铁律: 高一级优先
```

#### 3. 适用场景与失效边界

| 维度 | 具体表述 |
|---|---|
| 常态规律 | 三级同向时**通常**胜率最高。 |
| 环境要求 | **在**有连续历史数据**条件下**三图可比。 |
| 失效条件 | 重大重组致历史价格不可比时**失效**。 |
| 不适用场景 | 上市不足两年的新股**不适用**。 |
| 适用范围 | **仅适用**于数周至数月的波段交易。 |

#### 4. 避坑警示
月线仍向上时因一根日线长阴清仓，是最常见的错误。

#### 5. 跨场景应用示例
- **资产管理**：十年定配置、年度定战术、月度定调仓。

---

### 模型2：三点确认模型（突破与跌破的缓冲带）

#### 1. 核心定义
突破或跌破必须以超过前高前低三个点为确认阈值；确认后回抽跌破前高下方三点，则突破失效。

#### 2. 原理机制
关键价位聚集大量止损单与挂单，价格常短暂假突破以触发这些订单。三点缓冲带把「触及」与「站稳」区分开：只有穿过且回抽不破，才说明买方真正接管该价位。该阈值同时给出挂单位置，风险被限定在六点内。

#### 模型公式

```
突破: 价>前高+3 且回抽不破前高−3
买点: 前高−3 ~ +1
止损: 前高−3
```

#### 3. 适用场景与失效边界

| 维度 | 具体表述 |
|---|---|
| 常态规律 | 三点带**通常**能过滤大部分日内假突破。 |
| 环境要求 | **在**价格连续无跳空**条件下**可直接套用。 |
| 失效条件 | 除权或消息跳空时**失效**，须重算基准。 |
| 不适用场景 | 低价股与超高价股**不适用**统一阈值。 |
| 适用范围 | **仅适用**于 20~200 美元的活跃个股。 |

#### 4. 避坑警示
把「触及前高」当「突破前高」是头号误用。

#### 5. 跨场景应用示例
- **产品发布**：新功能须超过基线一定幅度并稳定一段时间才算成功。

### 模型3：底顶形态买卖模型（单底、双底、三底及其镜像）

#### 1. 核心定义
在单底、双底、三重底形成时买入，在单顶、双顶、三重顶形成时卖出，止损统一设在形态外侧不超过三点。

#### 2. 原理机制
价格在同一水平反复获得支撑，说明该价位存在稳定买盘；反复受阻则说明存在稳定卖压。第二、三次测试更可靠，因为每次测试都在消耗对方弹药。第四次到达同一水平时，江恩的经验是趋势通常选择突破而非折返。

#### 模型公式

```
买: 单底横盘2~3周/双底/三底
卖: 单顶/双顶/三顶
止损: 底−1~3 或 顶+1~3
```

#### 3. 适用场景与失效边界

| 维度 | 具体表述 |
|---|---|
| 常态规律 | 三重底顶**通常**比单次测试更可靠。 |
| 环境要求 | **在**形态期成交量递减**条件下**可靠性最高。 |
| 失效条件 | 第三次测试放量破位时形态**失效**。 |
| 不适用场景 | 跨度不足两周的整理**不适用**。 |
| 适用范围 | **仅适用**于形态低高点相距不超过 5% 的情形。 |

#### 4. 避坑警示
下跌趋势中把每次反弹当双底，是形态交易者最常见的亏损来源。

#### 5. 跨场景应用示例
- **招聘决策**：同一岗位三次招聘同类人才均失败，问题在岗位设计。

### 模型4：量能与强弱模型（顶部放量、底部缩量、时点差辨强弱）

#### 1. 核心定义
以顶部放量、底部缩量、反弹缩量验证价格结论；以个股相对大盘见顶见底的时点差判断强弱。

#### 2. 原理机制
成交量记录双方投入的兵力：顶部放量说明卖方大量出货，底部缩量说明卖方已无筹码；缩量反弹说明买方不愿追高。时点差暴露主力意图：提前见顶说明已派发完毕，提前见底说明正在吸筹。

#### 模型公式

```
顶: 长牛末放量
底: 长跌后缩量+波幅收窄
反弹: 缩量→趋势仍向下
强弱: 见顶/见底时点差≥数月
```

#### 3. 适用场景与失效边界

| 维度 | 具体表述 |
|---|---|
| 常态规律 | 量价配合**通常**提前一至两周给出顶底提示。 |
| 环境要求 | **在**成交量真实、无协议转让**条件下**可靠。 |
| 失效条件 | 指数调整或衍生品主导成交时**失效**。 |
| 不适用场景 | 单笔交易即可显著放量的冷门股**不适用**。 |
| 适用范围 | **仅适用**于有连续成交量数据的标的。 |

#### 4. 避坑警示
只看放量不问位置，是量能分析最常见的误读。

#### 5. 跨场景应用示例
- **用户增长**：新增激增但留存下滑，是典型的「顶部放量」。

### 模型5：七法则执行模型（资金、止损、买卖点、加仓、转换）

#### 1. 核心定义
以七条法则覆盖资金规模、止损、买入点、卖空点、金字塔加仓、多空转换与量能验证。

#### 2. 原理机制
设计逻辑是「先定风险，再定方向，最后定节奏」。第一、二条定资金与止损，第三、四条把买卖点绑定在形态与三点突破，第五条按价格区间调整加仓间隔，第六条处理反转切换，第七条用量能验证。七条互相咬合，缺一失效。

#### 模型公式

```
1 资金: 单次≤1/10
2 止损: 1~3点, 风险≤5点
3 买点: 双底/突破回调
4 卖点: 双顶/破位反弹
5 加仓: 每5点或10点
6 转换: 止损即反手
7 量能: 顶放底缩
```

#### 3. 适用场景与失效边界

| 维度 | 具体表述 |
|---|---|
| 常态规律 | 七条同步执行**通常**产生小亏多次、大赚少数的正期望。 |
| 环境要求 | **在**可挂条件单、滑点可控**条件下**可无损执行。 |
| 失效条件 | 主力针对三点阈值扫损时**失效**，须加量能过滤。 |
| 不适用场景 | 无法挂条件单的市场**不适用**。 |
| 适用范围 | **仅适用**于完整执行含反手的交易者。 |

#### 4. 避坑警示
最易被破坏的是第六条——止损触发后不敢反手。止损不是认输，是换方向。

#### 5. 跨场景应用示例
- **项目管理**：预算上限、里程碑止损、分阶段追加、失败即转向。
