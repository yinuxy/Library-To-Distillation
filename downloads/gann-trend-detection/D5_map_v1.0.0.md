### 适用边界与失效条件

| 维度 | 具体表述 |
|---|---|
| 常态规律 | 三点确认**通常**在活跃中大盘股上最有效。 |
| 环境要求 | **在**可挂止损单、无涨跌停限制**条件下**阈值可直接套用。 |
| 失效条件 | 遇并购、拆股或指数调整导致跳空时，三点阈值**失效**。 |
| 不适用场景 | 买卖价差已超过三个点的冷门股**不适用**。 |
| 适用范围 | 金字塔加仓**仅适用**于首笔已浮盈的头寸。 |
