### 模型1：品种结构优势模型（为什么期货比股票更适合技术交易）

#### 1. 核心定义
以品种结构差异判断某套技术方法是否适用：方向单一、品种少、无分红干扰的市场，趋势判据更稳定。

#### 2. 原理机制
股票存在板块分化，指数上涨时仍有大量个股下跌，因此个股判据必须叠加相对强弱；期货所有合约跟随同一供求趋势，判断一次即可覆盖全品种。此外期货无分红、拆股、清算退市等公司行为干扰，价格序列更连续，历史阻力位的有效性更高。

#### 模型公式

```
适用性 = 方向单一性 × 价格连续性 × 品种集中度
期货: 高 × 高 × 高
股票: 低 × 中 × 低（需叠加相对强弱）
```

#### 3. 适用场景与失效边界

| 维度 | 具体表述 |
|---|---|
| 常态规律 | 单一趋势品种**通常**可直接套用趋势判据。 |
| 环境要求 | **在**价格序列连续、无公司行为干扰**条件下**最有效。 |
| 失效条件 | 当品种受政策限价长期扭曲时**失效**。 |
| 不适用场景 | 多板块分化明显的股票市场**不适用**单一判据。 |
| 适用范围 | **仅适用**于供求主导、交割标准化的商品合约。 |

#### 4. 避坑警示
把期货的单一趋势判据直接用于个股，会忽略板块分化，导致大量假信号。

#### 5. 跨场景应用示例
- **方法迁移**：把某行业有效的管理方法搬到另一行业前，先核对结构差异。

### 模型2：百分比阻力模型（50% 半路点与八等分）

#### 1. 核心定义
以最高卖出价与最低卖出价的差值划分百分比（50%、整数百分比、八等分、三等分），作为阻力与买卖点。

#### 2. 原理机制
价格区间记录了多空双方的成本分布。50% 位是平均成本线，跌破后上方全部持仓转为亏损，抛压最重；八等分与三等分则对应不同的持仓成本簇。江恩认为这些位置之所以有效，是因为它们对应真实的成本分布，而非神秘数字。

#### 模型公式

```
区间 = 最高卖出价 − 最低卖出价
阻力 = 最低价 + 区间 × k, k ∈ {1/8,1/4,1/3,1/2,2/3,3/4,7/8}
最重要: k = 1/2（半路点）
```

#### 3. 适用场景与失效边界

| 维度 | 具体表述 |
|---|---|
| 常态规律 | 50% 位**通常**是最强阻力或支撑。 |
| 环境要求 | **在**最高最低价具有代表性**条件下**有效。 |
| 失效条件 | 当区间由单日异常波动造成时**失效**。 |
| 不适用场景 | 上市初期数据不足的合约**不适用**。 |
| 适用范围 | **仅适用**于已形成明确历史区间的成熟合约。 |

#### 4. 避坑警示
把任意两个价格当区间，是最常见的误用。区间必须取自极限高低点。

#### 5. 跨场景应用示例
- **薪酬谈判**：以行业区间中位数（50% 位）为锚，而非以对方首次报价为锚。

### 模型3：突破点与摆动模型（时间耗尽后的能量释放）

#### 1. 核心定义
在吸筹或派发耗尽时间后的第一个有效突破处建仓，随后以周线摆动图的低点买入、高点减仓，只做与主趋势同向的摆动。

#### 2. 原理机制
横盘整理是买卖双方在狭窄区间内反复消耗的过程。整理时间越长，双方持仓成本越集中，一旦突破，止损盘与追单同时涌入，形成快速单边行情。摆动交易则利用主趋势中的次级回撤，在回撤低点买入，把成本控制在趋势的有利一侧。

#### 模型公式

```
突破点 = 整理区间上沿 + 有效突破确认
买点 = 摆动低点（回撤不破前低）
减仓 = 摆动高点（未创新高）
铁律: 只做顺向摆动
```

#### 3. 适用场景与失效边界

| 维度 | 具体表述 |
|---|---|
| 常态规律 | 整理越久，突破后**通常**行情越大。 |
| 环境要求 | **在**可识别清晰整理区间**条件下**有效。 |
| 失效条件 | 假突破后快速回归区间时**失效**。 |
| 不适用场景 | 无明确区间的单边急涨急跌**不适用**。 |
| 适用范围 | **仅适用**于与主趋势同向的摆动。 |

#### 4. 避坑警示
逆势做摆动，等于在下跌趋势中接飞刀。摆动交易的前提是主趋势明确。

#### 5. 跨场景应用示例
- **产品上线**：长期打磨后的首个版本往往带来最大增长，之后进入迭代摆动。

### 模型4：时间周期与缺口模型（时间逆转与缺口性质）

#### 1. 核心定义
以重要顶底起算的时间间隔寻找重复周期，当周期耗尽而价格未创新高或新低即为转折信号；缺口按位置分为突破、持续、衰竭三类，性质不同。

#### 2. 原理机制
时间是推动力耗尽的过程。当价格在相近的时间间隔后再次到达极值区，说明周期在重复；若时间已到而价格未能创新高，说明买方力量已不足以维持节奏。缺口则记录情绪的突然释放：突破缺口出现在整理末端，持续缺口出现在行情中段，衰竭缺口出现在末端且常被快速回补。

#### 模型公式

```
周期: 自顶底起 N 日/周/月重复
转折: 时间到而价格未创新高/低
缺口: 突破（放量、不回补）/ 持续（中段）/ 衰竭（末端、快速回补）
```

#### 3. 适用场景与失效边界

| 维度 | 具体表述 |
|---|---|
| 常态规律 | 时间周期**通常**在相近间隔后重复。 |
| 环境要求 | **在**历史数据充足、合约连续**条件下**可标定。 |
| 失效条件 | 制度变革或长期停牌打乱时间连续性时**失效**。 |
| 不适用场景 | 上市不足两年的合约**不适用**长周期。 |
| 适用范围 | **仅适用**于作为关注窗口，须与价格判据配合。 |

#### 4. 避坑警示
把时间周期当精确日期，是周期方法最危险的用法。周期只提示窗口。

#### 5. 跨场景应用示例
- **宏观研究**：库存周期与信贷周期叠加，判断共振窗口。
