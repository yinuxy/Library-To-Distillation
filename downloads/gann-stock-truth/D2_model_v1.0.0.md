### 模型一：供求天平模型（大盘看盘第一性原理）

#### 1. 核心定义
看盘不是预测未来的水晶球，而是通过连续行情记录客观度量多空双方供求力量转移的动态天平。脱离供求位置的单点价格毫无意义。

#### 2. 原理机制
大盘记录着全市场所有资金、内幕、心理与预期的合力。当买方需求压倒卖方供给时，价格重心必然上移；反之供给过剩则价格坍塌。主力的对倒、洗盘与操纵可能会在分时制造假象，但绝无法在关键技术位置上长期伪造真实的供求量价结构。

#### 3. 字符与图形示意
```
    [ 买方需求 > 卖方供给 ]  ==>  价格突破阻力位，重心稳步抬升 (多头主升)
               ▲
               │ 供求天平支点（行情记录与关键位置）
               ▼
    [ 卖方供给 > 买方需求 ]  ==>  价格击穿支撑位，毫无接盘下杀 (空头破位)
```

#### 4. 适用场景与失效边界
- **常态规律**：本模型**通常**在流动性充分、撮合公开竞价的二级市场中发挥最高效度。
- **典型表现**：放量突破阻力位**往往**确立买方力量处于绝对支配地位。
- **环境要求**：**在**多空博弈自由、规则透明的市场**条件下**最为敏锐。
- **失效条件**：当市场遭遇行政暴力干预、无涨跌幅熔断停牌或虚假对敲占成交量 90% 以上时，技术供求**失效**。
- **不适用场景**：交投极度清淡、流动性锁死的场外协议转让或无量仙股**不适用**。
- **适用范围**：**仅适用**于具备连续行情走势图与真实成交量的活跃标的。

#### 5. 避坑警示
切勿试图凭空猜测顶部或底部；绝不要听信内幕消息或小道传闻，大盘本身就是最权威的内幕。

#### 6. 跨场景应用示例
- **股票投资**：通过成交量放大与价格突破确认主力真实建仓，而非听信研报叙事。
- **商品期货**：以现货库存仓单变化与期货盘面升贴水检验真实供求弹性。
- **商业经营**：监测核心商品周转率与渠道去库存天数，判断行业景气拐点。

### 模型二：七个行动区域模型（周期估值与饱和点预警）

#### 1. 核心定义
以股票内在正常价值为基准中轴，向上划分三个上涨阶梯（隐蔽启动区、活跃加速区、极端狂热派发区），向下划分三个下跌阶梯（破位下跌区、恐慌加速区、极度绝望吸筹区），形成量化周期位置的七阶坐标系。

#### 2. 原理机制
- **正常价值区（第4区/中枢）**：股价与企业资产、盈利能力和公允回报大致匹配，窄幅震荡。
- **上方第1~2区**：业绩改善或预期向好，主力稳步推升，走势健康活跃。
- **派发第3区（极端狂热）**：公众贪婪入场，各种虚假利好满天飞，主力大举分批出货。当供求达到**饱和点**时，即使毫无利空，股票在早盘直接跳空低开1~5点，即为主力撤除买单、供给彻底压倒需求的**首道预警闪电**。
- **下方第1~2区**：估值泡沫破裂，多头解套幻想破灭，价格逐级崩塌。
- **吸筹第3区（极度绝望）**：股价跌至荒谬低位，股票弃若敝履，公众斩仓离场。此时即使重大利空出台股价也拒不再跌（利空钝化），聪明资金在箱体中悄悄吸筹。

#### 3. 字符与图形示意
```
    [区域7] 派发第三区 ★ 极端狂热 / 公众盲从 / 饱和点闪电跳空低开 (坚决出局/反手做空)
    [区域6] 活跃第二区 ▲ 趋势加速 / 成交活跃 / 浮盈金字塔加仓
    [区域5] 启动第一区 ▲ 脱离底部 / 阻力突破 / 初始试探建仓
  ════════════════════════════════════════════════════════════════════════════════
    [区域4] 正常价值区 ── 企业内在公允估值中枢 / 多空平衡窄幅震荡
  ════════════════════════════════════════════════════════════════════════════════
    [区域3] 破位第一区 ▼ 跌破支撑 / 估值回归 / 严格触发保护性止损
    [区域2] 恐慌第二区 ▼ 杀跌加速 / 踩踏出清 / 顺势做空或空仓观望
    [区域1] 吸筹第三区 ★ 极度绝望 / 利空钝化 / 聪明资金逆向建仓 (平空翻多)
```

#### 4. 适用场景与失效边界
- **常态规律**：大盘蓝筹与龙头行业**通常**呈现清晰的七区域周期循环。
- **典型表现**：狂热派发区**往往**伴随全社会普遍性的非理性亢奋与杠杆资金激增。
- **环境要求**：**在**经历长期牛市或熊市充分洗礼的宏观周期**条件下**有效性极高。
- **失效条件**：遭遇突发战争、法币恶性通胀或主权债务违约时，正常价值锚点**失效**。
- **不适用场景**：处于初创爆发期、商业模式剧烈颠覆的零收入高科技早期项目**不适用**。
- **适用范围**：**仅适用**于具备稳定盈利记录或明确资产重置成本的成熟型资产。

#### 5. 避坑警示
切勿在派发第三区被乐观情绪催眠而加杠杆追高；切勿在吸筹第三区因漫无边际的利空传闻而在地板上割肉。

#### 6. 跨场景应用示例
- **股票投资**：利用 PE/PB 历史百分位结合技术走势定位七个区域，杜绝高位接盘。
- **房地产投资**：以租售比、居民收入房贷比为锚，识别资产泡沫第三区与绝望出清第三区。
- **宏观资产配置**：在美林时钟大类资产轮动中定性各大类资产所处的周期台阶。

### 模型三：金字塔浮盈顺势加仓模型（风险锁定与非对称暴利引擎）

#### 1. 核心定义
顺应明确的波段大趋势，仅在已有头寸产生充足浮盈且股价突破新的关键阻力位时，按递减比例追加新头寸，同时将全仓止损单同步上移至初始成本之上，实现下行风险锁死、上行收益无限的非对称盈利结构。

#### 2. 原理机制
绝大多数失败者习惯在亏损时逆势摊平，导致亏损成倍扩大最终爆仓。江恩金字塔加仓完全相反：首笔单点试错成功确立盈利优势；随着行情突破前高追加第二笔；同步上移总止损单使得即便突发反转，平仓收益依然为正。这一机制利用市场趋势本身提供的盈利安全垫抵御波动，在单边主升浪中实现几何级复利。

#### 3. 字符与图形示意
```
            ▲
           / \     第3笔加仓: 100 股 (突破历史极值阻力，止损上移至保本位+5点)
          /───         /     \    第2笔加仓: 200 股 (顺势突破第一阻力，止损上移至初始买价之上)
        /───────       /         \   初始底仓: 400 股 (双底企稳或突破启动，挂 1~3 点保护性止损)
      ─────────────
```

#### 4. 适用场景与失效边界
- **常态规律**：本模型**通常**在波澜壮阔的大级别单边主升或主跌大趋势中获取暴利。
- **典型表现**：突破加码**往往**伴随动量加速，让持仓均价始终处于市价的安全后方。
- **环境要求**：**在**趋势明确、流动性优异且换手良性的龙头股**条件下**运行最佳。
- **失效条件**：在宽幅剧烈拉锯的无方向震荡市中频繁追高加仓会导致止损被反复扫中，策略**失效**。
- **不适用场景**：成交萎靡、微小买盘即导致大幅跳价的流动性受限标的**不适用**。
- **适用范围**：**仅适用**于既有仓位已有充分利润垫且顺势突破阻力的情形，严禁亏损加仓。

#### 5. 避坑警示
**死穴警告**：严禁倒金字塔加仓（高位加码大于底仓）！严禁逆势摊平补仓！一旦倒置，微小回调即可瞬间吃光全部浮盈并穿透本金。

#### 6. 跨场景应用示例
- **量化动量交易**：基于突破信号的自适应加仓与动态跟踪止盈算法。
- **风险投资 (VC)**：对跑通商业模式并爆发式增长的明星领头羊项目行使超额追加投资权。
- **项目研发管理**：对通过里程碑验证的核心产品线追加战略资源，对停滞项目断然止损。

### 模型四：刚性止损与移动保本模型（资本保全绝对防线）

#### 1. 核心定义
在建立任何交易头寸的同时，必须毫秒级挂设 1~3 点（或总资本 10%）以内的保护性止损单；当走势顺向发展获得收益后，必须毫不迟疑地将止损单上移至保本价位之上，绝不允许账面盈利转变为亏损。

#### 2. 原理机制
交易是概率与赔率的长期博弈。没有人能拥有 100% 胜率，长胜的核心在于非对称性：通过 1~3 点的小额刚性止损截断亏损，将单次犯错的代价限制在可承受的极窄边界内；通过移动保本将纸面富贵固化为确定性防线，使资金永远处于“要么大赚，要么小亏，绝不致命”的安全结界中。

#### 3. 适用场景与失效边界
- **常态规律**：刚性止损**通常**是区分 2% 专业赢家与 98% 业余赌徒的试金石。
- **典型表现**：执行止损**往往**伴随短期的心理阵痛，但能换取长期的账户生存权。
- **环境要求**：**在**支持条件单、止损单自动市价触发的电子化经纪商交易环境**条件下**成立。
- **失效条件**：遭遇巨额跳空无量跌停开盘导致滑点极其严重时，常规技术止损点位**失效**，需靠事前仓位限额兜底。
- **不适用场景**：没有任何流动性与撮合报价的协议股权质押**不适用**。
- **适用范围**：**仅适用**于所有场内标准化现货、期货、期权头寸开立的第一秒。

#### 4. 避坑警示
绝不要在入场后手动下调或撤销已挂设的止损单；绝不可心存“等反弹解套再走”的侥幸心理。

#### 5. 跨场景应用示例
- **企业财务管理**：对单笔高风险应收账款或海外汇率风险设定 5% 刚性对冲止损线。
- **个人负债风控**：设定家庭流动性资产抵御刚性月供开支的 6 个月绝对安全警戒线。

### 模型五：相对强弱与板块动量模型（机构主力穿透与龙头捕捉）

#### 1. 核心定义
大盘总趋势下挫时逆势抗跌甚至收阳的个股，在大盘止跌企稳时必为领涨主升的超级龙头；反之大盘上涨时滞涨、稍有回调便创新低的股票，必为主力资金持续出逃的领跌毒瘤。

#### 2. 原理机制
系统性大盘暴跌是对全市场个股最严酷的“压力测试”。若某只股票在恐慌暴跌中拒不下跌反而逆势放量抗跌，必然意味着主力大资金在底层全力扫货、高度锁仓，甚至已经将浮筹清洗殆尽。大盘企稳之日，正是该标的上方无套牢阻力、一飞冲天之时。

#### 3. 适用场景与失效边界
- **常态规律**：本模型**通常**在牛市初期的板块切换与熊市末期的黄金坑中产生最暴利的龙头标的。
- **典型表现**：龙头股**往往**比大盘提前 1~3 周见底，率先放量突破历史阻力位。
- **环境要求**：**在**行业具备长期成长逻辑或重大产业政策催化的标的**条件下**穿透力最强。
- **失效条件**：个股抗跌纯属单一庄家利用高比例质押进行无量护盘、后续被强平补跌时，相对强弱信号**失效**。
- **不适用场景**：成交量极小、全天振幅不足 0.5% 的死水僵尸股**不适用**。
- **适用范围**：**仅适用**于成交活跃、属于主流产业赛道前排的龙头个股。

#### 4. 避坑警示
切勿因弱势股“价格便宜、还没有涨”而试图捡便宜抄底；市场永远是强者恒强、弱者恒弱。

#### 5. 跨场景应用示例
- **行业选股策略**：在市场普遍调整时监控抗跌榜，筛选下阶段主升浪领跑龙头。
- **商业竞争分析**：在宏观行业寒冬期，逆势扩张市场份额且利润率提升的企业具备最强护城河。

### 模型六：双顶双底与突破动量模型（形态反转与主升浪确认）

#### 1. 核心定义
价格相隔数周至数月在同一水平两次受阻（双顶）或两次获得支撑（双底），是胜率极高的反转架构；当价格强势放量突破数月甚至数年的历史极值水平时，意味着上方筹码真空，将引发单边加速动量行情。

#### 2. 原理机制
前高前低水平沉淀了庞大的历史套牢盘或抄底获利盘。当价格第二次测试同一高位无法突破，表明多头弹尽粮绝，主力顺势派发转入熊市；反之双底确认代表供给衰竭。一旦价格以长阳彻底突破历史天花板，所有历史买家全员盈利，解套抛压荡然无存，空头被迫止损与技术买盘共振，形成暴烈的主升浪。

#### 3. 适用场景与失效边界
- **常态规律**：相隔时间越长（数月以上）的双顶双底与历史水平，其突破后的动量**通常**越持久。
- **典型表现**：突破瞬间**往往**伴随成交量的爆发式放大与买单跳跃。
- **环境要求**：**在**顺应道琼斯指数大盘中长期趋势的宏观**条件下**爆发力最强。
- **失效条件**：若突破仅维持极短时间便以长阴线跌回箱体内，构成假突破（诱多陷阱），原推论**失效**。
- **不适用场景**：无任何技术规律可循的内幕盘与操纵小票**不适用**。
- **适用范围**：**仅适用**于筹码充分换手、历史走势图清晰完整的标准化大盘标的。

#### 4. 避坑警示
切勿在价格尚未确认突破历史阻力或跌破支撑前主观盲猜；必须等待收盘确认有效突破方可执行市价追单。

#### 5. 跨场景应用示例
- **大宗商品交易**：突破长达数年的底部震荡大箱体上沿，确立超级大宗商品牛市周期。
- **量化 CTA 策略**：基于唐奇安通道与海龟交易法的长周期阻力突破开仓系统。

### 模型七：象鼻虫预期差定理（消息反应与真实供求试金石）

#### 1. 核心定义
消息字面本身绝不决定未来趋势，大盘在关键位置对消息的真实反应才是检验供求底牌与主力意图的终极试金石。

#### 2. 原理机制
江恩以棉籽象鼻虫灾害为例：全美媒体连篇累牍报道象鼻虫肆虐的大灾利空，散户公众惊慌失措做空，棉花期货价格却坚决不跌甚至反常上涨。这一反常反应揭示出致命真相：利空早已被市场充分消化，大买家正借助公众恐慌疯狂扫货锁仓！反之，当公司公布前所未有的巨额分红或超级利好，股价却放量滞涨或跳空回落，证明主力正在借利好全线出逃。

#### 3. 字符与图形示意
```
    [ 极端利空出台 ]  ───>  价格坚决拒跌，放量收阳  ==>  利空钝化 / 筹码锁死 / 底部确立 (逆向做多)
    [ 重大利好公布 ]  ───>  价格放量滞涨，冲高回落  ==>  利好出尽 / 主力派发 / 顶部崩塌 (坚决逃顶)
```

#### 4. 适用场景与失效边界
- **常态规律**：本定理**通常**在信息爆炸、新闻资讯高度过载的现代资本市场中具备绝佳反脆弱性。
- **典型表现**：超预期的反向走势**往往**伴随对手盘的被动挤压与踩踏止损。
- **环境要求**：**在**重大宏观经济数据（如非农、CPI、降息）或企业关键财报发布**条件下**效果极佳。
- **失效条件**：出现彻底毁灭企业或国家资产负债表的不可逆毁灭性打击时，利空拒跌并非底部，模型**失效**。
- **不适用场景**：完全没有公开信息披露的暗池私募交易**不适用**。
- **适用范围**：**仅适用**于所有全网高度关注、具有广泛公众参与的焦点资产。

#### 5. 避坑警示
绝不要盲信任何官方研报、媒体头条或分析师的字面推荐；只看市场对消息的真实量价反应。

#### 6. 跨场景应用示例
- **财报事件驱动交易**：业绩爆雷但股价低开高走收长阳，表明利空出尽，确立中期底部买点。
- **危机公关与舆情管理**：评估企业对重大负面公关事件的耐受力，以真实业务转化率检验品牌成色。
