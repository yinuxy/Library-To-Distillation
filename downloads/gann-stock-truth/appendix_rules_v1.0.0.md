### 边界与适用性说明

- **常态规律**：本卡所列军规**通常**在波段趋势清晰、流动性充裕的标准二级市场中具备稳定有效性。
- **典型表现**：突破阻力位后**往往**伴随成交量激增与多头动量加速。
- **环境要求**：**在**多空双向撮合、支持条件单自动执行的现代券商交易环境**条件下**有效性最高。
- **失效条件**：当遭遇不可抗力或交易所极端无量停牌时，常规技术止损**失效**。
- **不适用场景**：成交极度清淡、易被单一庄家操纵的无量微盘股**不适用**。
- **适用范围**：金字塔加仓法**仅适用**于已建立浮盈且顺势突破的标的，严禁用于亏损头寸。

### 跨场景应用示例

- **大宗商品期货**：将 28 条军规迁移至螺纹钢、原油、铜期货，配合商品季节周期执行突破跟踪与 1% 日内止损。
- **数字资产交易**：在 7x24 小时高波动市场通过 API 自动化部署条件止损与金字塔浮盈跟踪。
- **企业大宗采购风控**：将军规转化为企业原材料采购红线，严禁跌价周期中盲目囤货摊平库存。
