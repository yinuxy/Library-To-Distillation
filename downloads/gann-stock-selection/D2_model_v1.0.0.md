### 模型1：24 条规则模型（资金、买卖点、加仓的三组约束）

#### 1. 核心定义
以 24 条规则构成选股与交易的完整约束集，分为资金风险、买卖点、加仓持仓三组，每组均给出可执行阈值。

#### 2. 原理机制
规则的价值在于把「判断」前置。资金组规定单笔上限与止损位置，使错误可承受；买卖点组把入场绑定在突破与放量两类客观信号上，排除主观估值；加仓组规定只在突破阻力后加码且递减，使加仓成为浮盈的再分配而非风险的放大。三组互相咬合：没有资金约束，买卖点再准也会被一次重仓击穿；没有加仓纪律，正确判断也只能获得平庸收益。

#### 模型公式

```
资金组: 单笔≤本金固定比例 + 预设止损
买卖点组: 突破多年高点 / 放量转强 买入；跌破派发区 卖出
加仓组: 突破阻力后加码 + 递减加量
```

#### 3. 适用场景与失效边界

| 维度 | 具体表述 |
|---|---|
| 常态规律 | 三组同步执行**通常**产生正期望。 |
| 环境要求 | **在**可挂止损单的市场**条件下**可无损执行。 |
| 失效条件 | 主力针对突破位扫损时**失效**，需加量能过滤。 |
| 不适用场景 | 无法挂条件单的市场**不适用**。 |

#### 4. 避坑警示
最常见的破坏方式是「这次例外」——为一只「特别看好」的股票破例重仓。

#### 5. 跨场景应用示例
- **项目管理**：预算上限、里程碑验收、追加投入需先达里程碑。

### 模型2：突破历史高点模型（筹码真空与不回头的强势）

#### 1. 核心定义
当股票穿越多年前形成的最高价时，上方已无历史套牢盘，进入筹码真空区，往往呈现不回头的强势。

#### 2. 原理机制
历史最高价是全部历史买家的成本上限。价格在其下方运行时，任何上涨都要面对解套抛压；一旦穿越，所有历史持仓转为盈利，抛压骤减，同时空头被迫回补，形成自我强化的上涨。江恩特别指出，这类突破后的走势「甚至不会发生回调」，因为没有任何一方有动机在盈利区卖出。

#### 模型公式

```
信号: 价 > 多年前历史最高价
确认: 突破后回调不破该高点
止损: 该高点下方 3 点
加仓: 突破下一历史阻力位
```

#### 3. 适用场景与失效边界

| 维度 | 具体表述 |
|---|---|
| 常态规律 | 历史越久远的高点，突破后**通常**越强。 |
| 环境要求 | **在**价格未因拆股调整失真**条件下**可比。 |
| 失效条件 | 假突破后三日內跌回高点下方时**失效**。 |
| 不适用场景 | 上市不足三年无历史高点者**不适用**。 |

#### 4. 避坑警示
把「接近历史高点」当「突破历史高点」，是最常见的抢跑错误。

#### 5. 跨场景应用示例
- **职业发展**：突破行业历史天花板（如职级、薪酬带宽）后，议价空间显著扩大。

### 模型3：四级图表模型（年、月、周、日的层级分工）

#### 1. 核心定义
以年线判断历史位置、月线判断主趋势、周线判断波段、日线判断时机，四级各有分工且不可越权。

#### 2. 原理机制
年线回答「这只股票在历史上的位置」——是否处于历史新高区、是否处于长期底部；月线回答「主趋势方向」；周线回答「当前处于第几次回调」；日线只在活跃行情中回答「今天是否扣扳机」。层级越高的图表，结论越稳定；用日线推翻月线，等于用噪音否定信号。

#### 模型公式

```
年线 → 历史位置（新高区/底部区）
月线 → 主趋势方向
周线 → 波段位置
日线 → 入场时机
```

#### 3. 适用场景与失效边界

| 维度 | 具体表述 |
|---|---|
| 常态规律 | 四级同向时**通常**胜率最高。 |
| 环境要求 | **在**有足够历史数据**条件下**年线才有意义。 |
| 失效条件 | 重大重组致历史价格不可比时**失效**。 |
| 不适用场景 | 上市不足三年的新股**不适用**年线判位。 |

#### 4. 避坑警示
只看日线选股，会把短期反弹当成趋势启动。

#### 5. 跨场景应用示例
- **战略管理**：十年看行业、三年看公司、一年看业务、一月看执行。

### 模型4：周期与位置模型（繁荣末期的四个特征）

#### 1. 核心定义
以周期长度、总市值、成交量与利率水平判断市场处于繁荣、衰退、萧条还是复苏，并识别繁荣末期的特征。

#### 2. 原理机制
繁荣末期的特征具有高度重复性：成交量放大而涨幅收窄，说明买盘在承接抛压但已无力推高；领涨股开始滞涨，说明最强的一批资金已在撤退；公众参与度达到顶点，说明最后的接盘力量已经入场。这三个特征同时出现时，周期往往已接近耗尽。

#### 模型公式

```
繁荣末期信号:
① 成交量放大但涨幅收窄
② 领涨股滞涨、补涨股活跃
③ 公众参与度创新高
```

#### 3. 适用场景与失效边界

| 维度 | 具体表述 |
|---|---|
| 常态规律 | 三特征同时出现**通常**预示周期尾部。 |
| 环境要求 | **在**有连续总量数据**条件下**可观测。 |
| 失效条件 | 制度性变革（如新交易机制）使旧周期**失效**。 |
| 不适用场景 | 缺乏历史总量数据的新兴市场**不适用**。 |

#### 4. 避坑警示
把「成交量创新高」当成「行情还会继续」，是最典型的顶部误读。

#### 5. 跨场景应用示例
- **行业研判**：新增用户创新高但 ARPU 下滑，是行业见顶的经典组合。

### 模型5：领涨股时点模型（早期与后期领涨股的区分）

#### 1. 核心定义
早期领涨股在大盘见底前率先止跌蓄势并第一个突破；后期领涨股在大盘上涨中后段才启动，涨幅快但持续性差。

#### 2. 原理机制
早期领涨股的强势来自主力在低迷期的持续吸筹，因此大盘一转暖就能立刻拉升；后期领涨股的强势来自情绪扩散，资金是追涨而非建仓，因此一旦情绪退潮就迅速回落。区分二者的方法是看启动时点与蓄势时长：蓄势越久、启动越早，持续性越强。

#### 模型公式

```
早期领涨: 先于大盘止跌 + 窄幅蓄势 + 率先突破
后期领涨: 大盘中后段启动 + 涨幅快 + 无蓄势
警戒: 快速上涨 6~7 周即接近摆动顶
```

#### 3. 适用场景与失效边界

| 维度 | 具体表述 |
|---|---|
| 常态规律 | 早期领涨股**通常**在下一轮行情中涨幅居前。 |
| 环境要求 | **在**有明确大盘基准**条件下**才能比较时点。 |
| 失效条件 | 行业逻辑独立于大盘时**失效**。 |
| 不适用场景 | 上市不足一个牛熊周期的个股**不适用**。 |

#### 4. 避坑警示
追逐已经涨了六七周的后期领涨股，是散户最常见的亏损方式。

#### 5. 跨场景应用示例
- **人才市场**：早期加入朝阳行业的人获得超额回报，后期涌入者往往承担均值回归。
