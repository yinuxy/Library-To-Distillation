### 模型1：双层趋势判据模型（趋势线指标与三日图的分工）

#### 1. 核心定义
用两套独立构造的趋势线分别刻画两个时间尺度的趋势：趋势线指标跟随每日更高的顶部与更高的底部移动，刻画次级趋势；三日图只在连续三日创出更高底部与更高顶部时才上移，刻画主趋势。

#### 2. 原理机制
次级趋势是主趋势的组成部分，但波动频率更高，易被单日噪音触发。若用同一套判据管理两个尺度，必然出现「战术信号推翻战略结论」的错误。江恩用两套阈值把它们隔开：趋势线被穿越 1 美分只说明次级趋势反转，三日图底部被跌破才说明主趋势反转。

#### 模型公式

```
次级反转 = 穿越趋势线顶/底 1 美分
主趋势反转 = 破三日图底/顶
仓位: 次级→减仓; 主趋势→清仓反手
```

#### 3. 适用场景与失效边界

| 维度 | 具体表述 |
|---|---|
| 常态规律 | 两级判据**通常**在趋势清晰的行情中给出高度一致的结论。 |
| 环境要求 | **在**每日交易时段完整、无频繁跳空的市场**条件下**判据最可靠。 |
| 失效条件 | 当出现连续涨跌停或隔夜跳空超过 3 美分时，三日图**失效**，须改用信号日规则。 |
| 不适用场景 | 日内高频交易与分钟级 scalping**不适用**三日图框架。 |
| 适用范围 | **仅适用**于持倉周期在数日至数周的趋势/波段交易。 |

#### 4. 避坑警示
最常见的致命错误，是在三日图仍向上时因一次日内急跌而清仓反手。江恩的处置很明确：主趋势未变，回调即买点，止损放在次级趋势下方即可。

#### 5. 跨场景应用示例
- **股票指数交易**：用周线定主趋势、日线定次级，避免用日内波动推翻周线结论。

### 模型2：29 条规则机械化模型（把交易决策编译为固定阈值）

#### 1. 核心定义
以 29 条编号规则覆盖建仓、加仓、止损、反手、离场全流程，每条规则均给出可量化的触发条件与阈值，使交易决策可被第三方复现。

#### 2. 原理机制
规则化的本质是把「判断」前置到规则设计阶段，把「执行」压缩为条件匹配。江恩的规则设计有三个特征：阈值极窄、方向唯一（触发即反手，不含观望）、条件复合（价格 + 收盘位置 + 时间天数）。三者共同压缩了临场裁量空间。

#### 模型公式

```
规则2: 双底/三底买, 第三底风险≤1美分
规则4: 第四次到同水平→换向加仓
规则7: 连跌涨7~10日→止损移至日顶/底外1美分
规则13: 双顶底附近禁二次加仓
```

#### 3. 适用场景与失效边界

| 维度 | 具体表述 |
|---|---|
| 常态规律 | 规则集**通常**在活跃合约上产生正期望，在清淡合约上频繁误触发。 |
| 环境要求 | **在**可挂条件单、滑点可控的电子交易**条件下**规则才可无损执行。 |
| 失效条件 | 当主力利用规则共识进行假突破扫损时，纯规则系统**失效**，须加入成交量或时间过滤。 |
| 不适用场景 | 流动性不足、买卖价差超过止损距离的合约**不适用**。 |
| 适用范围 | **仅适用**于规则被完整执行（含反手动作）的交易者，选择性执行会使期望值转负。 |

#### 4. 避坑警示
规则的最大敌人不是市场，是「这次不一样」的侥幸。江恩在规则 21、22 中特意加入「毫不犹豫」四字，正是针对执行环节的迟疑。

#### 5. 跨场景应用示例
- **量化策略开发**：把主观交易逻辑编译为带阈值的 if-then 规则，再做历史回测。

### 模型3：金字塔顺势加仓模型（浮盈加码与止损同步上移）

#### 1. 核心定义
在已建立浮盈且趋势未变的前提下，按固定价格间隔（谷物 5 美分、棉花 40~50 美分）分批同向加仓，同时将全仓止损同步上移至新的趋势线外侧，使加仓后整体风险不增加。

#### 2. 原理机制
加仓的资金来源是市场已给出的浮盈，而非原始本金。价格顺向移动 5 美分时，首笔浮盈已足以覆盖新增头寸的止损风险；止损同步上移后，即使全部头寸被止损，账户仍为净盈利。这一结构把加仓从风险放大动作转化为风险对冲动作。江恩同时设禁令：绝不在双重顶底附近做二次加仓。

#### 模型公式

```
初始 1 手, 止损=趋势线底−1美分
每+5美分(棉花+40~50)加1手, 止损上移
满5手时挂6手反向止损, 留1手反向敞口
```

#### 3. 适用场景与失效边界

| 维度 | 具体表述 |
|---|---|
| 常态规律 | 本模型**通常**在单边趋势行情中贡献主要利润。 |
| 环境要求 | **在**趋势连续、回调幅度小于加仓间隔的市场**条件下**效果最佳。 |
| 失效条件 | 震荡市中价格反复穿越加仓间隔，止损被连续扫中，模型**失效**并加速亏损。 |
| 不适用场景 | 无明确趋势、日波幅小于加仓间隔的品种**不适用**。 |
| 适用范围 | **仅适用**于浮盈已覆盖新增头寸风险的情形，严禁用本金为加仓兜底。 |

#### 4. 避坑警示
倒金字塔（越加越大）是爆仓的标准配方。江恩要求每次加仓规模相等或递减，且止损必须同步上移，二者缺一不可。

#### 5. 跨场景应用示例
- **风险投资**：对已跑通里程碑的项目追加投资，用项目自身现金流而非母基金兜底。

### 模型4：几何角度线强弱模型（用斜率把趋势强度可视化）

#### 1. 核心定义
以时间单位为横轴、价格单位为纵轴，从重要顶底或「0」位出发按固定价格/时间比率绘制射线，用价格所处的射线档位判断趋势强弱，用射线被跌破的顺序判断下一支撑。

#### 2. 原理机制
角度线的本质是把「涨得多快」转化为可比较的斜率。每单位时间涨 8 点为极强，4 点为很强，2 点为强，1 点（45°）为平衡。价格跌破一条射线，意味着上涨速率已低于该档，必然向下一条更低速率的射线寻找支撑。这一「降档」机制使转弱成为渐进可观测的过程。

#### 模型公式

```
强势: 45°→2×1(63.75°)→4×1(75°)→8×1(82.5°)
熊市: 45°→2×1(26.25°)→4×1(15°)→8×1(7.5°)
铁律: 跌破任一条→跌向更低一条
```

#### 3. 适用场景与失效边界

| 维度 | 具体表述 |
|---|---|
| 常态规律 | 角度线**通常**在中期趋势中提供有效的动态支撑与阻力。 |
| 环境要求 | **在**图表刻度统一（如 1/8 英寸 = 1 美分）、时间轴连续**条件下**角度值才准确。 |
| 失效条件 | 当图表比例被拉伸或压缩、或交易日与日历日混用时，角度值**失效**，射线失去意义。 |
| 不适用场景 | 无连续时间轴的点阵图或等价图**不适用**。 |
| 适用范围 | **仅适用**于从重要顶底或「0」位起算的射线，任意点起算的角度线无效。 |

#### 4. 避坑警示
角度线最常见的误用，是在错误的起点画线。江恩明确要求从极限高低点、次级高低点或「0」位起算，任意起点的角度线只是一条普通斜线。

#### 5. 跨场景应用示例
- **增长分析**：把营收增速换算为「每季度增长多少」的斜率，跌破斜率即预警。

### 模型5：时间—价格正方模型（涨幅与时长相等即为平衡点）

#### 1. 核心定义
当价格上涨或下跌的点数，等于其运行的日、周或月数时，时间与价格达成正方，趋势处于平衡状态，最容易发生转折。三种正方分别以极限高低点幅度、极限低点、极限高点为基准。

#### 2. 原理机制
正方模型的深层假设是：市场运动存在速率守恒。一段行情以每单位时间 1 点的速率推进时，时间与价格同步增长，形成 45° 线；当价格偏离过远，就必须通过横盘或反向运动回到平衡。因此正方点不是神秘数字，而是速率回归的力学位置。江恩用 52×52、144、360 等正方网格标定这些位置。

#### 模型公式

```
基础正方：涨幅（点）= 运行时间（日/周/月）
幅度正方：|高点 − 低点| = N 日/周/月
低点正方：低点价格 = N 日/周/月
高点正方：高点价格 = N 日/周/月
周网格：52×52，关注 13 / 26 / 39 周
月网格：144，关注 36 / 48 / 72 / 108 / 144 月
```

#### 3. 适用场景与失效边界

| 维度 | 具体表述 |
|---|---|
| 常态规律 | 正方点**通常**对应趋势的中继整理或反转节点。 |
| 环境要求 | **在**能从极限顶底准确起算、且时间轴无缺失**条件下**正方点才有效。 |
| 失效条件 | 当合约中途修改规格或出现长期停牌时，时间连续性被破坏，正方**失效**。 |
| 不适用场景 | 新上市、历史数据不足一个完整正方周期的合约**不适用**。 |
| 适用范围 | **仅适用**于以极限顶底为基准的正方计算，任意起点的正方无意义。 |

#### 4. 避坑警示
正方点给出的是「易转折区」，不是「必然反转点」。江恩要求必须同时有角度线被跌破或三日图转向作为确认，单凭正方点入场是误用。

#### 5. 跨场景应用示例
- **项目周期管理**：工作量（人月）与计划工期相等时进入交付临界点，须预留缓冲。

### 模型6：时间周期共振模型（「12」的倍数与长短周期叠加）

#### 1. 核心定义
以「12」及其倍数为主轴，叠加 90/84/60/49/45/30/20 年长周期与 13/10/7/5/3 年次级周期，当多个周期在同一时间窗口重合时，转折概率显著上升。

#### 2. 原理机制
单一周期的转折信号误报率高，因为市场同时受多个尺度的节律支配。江恩的做法是构建周期谱系，要求长短周期在同一窗口共振。他还引入「空转时间」概念：时间也会像机械一样存在缓冲，需容忍 1~3 个单位的误差。共振加缓冲，构成了对周期方法最常见的两种误用（单周期决策、过度精确）的修正。

#### 模型公式

```
主轴：12 的倍数（12/24/36/48/60/72/84/96/108/120/132/144 月）
长周期：90 / 84 / 60 / 49 / 45 / 30 / 20 年
次周期：13 / 10 / 7 / 5 / 3 / 2 / 1 年
共振判据：≥2 个不同尺度周期在同一窗口（±1~3 单位）重合
```

#### 3. 适用场景与失效边界

| 维度 | 具体表述 |
|---|---|
| 常态规律 | 多周期共振窗口**通常**对应较大级别的转折。 |
| 环境要求 | **在**历史数据跨越至少两个长周期**条件下**谱系才可标定。 |
| 失效条件 | 当市场结构发生制度性变化（如取消金本位、改为电子撮合）时，旧周期**失效**。 |
| 不适用场景 | 历史不足 20 年的新品种**不适用**长周期谱系。 |
| 适用范围 | **仅适用**于作为「关注窗口」而非「精确买卖点」，须与价格判据配合。 |

#### 4. 避坑警示
周期方法最危险的用法，是把窗口当作精确日期。江恩自己给出「空转时间」缓冲，正是承认周期只能定位区间，不能定位时点。

#### 5. 跨场景应用示例
- **宏观研究**：用库存周期、产能周期、信贷周期叠加，判断共振窗口。

### 模型7：主计算图表多图互证模型（144 主方图与 12/9/六边形/360 圆图）

#### 1. 核心定义
以 144 主方图为核心，配合 12 主图、9 方图、六边形图与 360° 圆图，四种独立构造方式分别给出阻力位与时间位，取交集作为高置信转折区。

#### 2. 原理机制
四种图表的构造逻辑彼此独立：144 主方图基于 12 的平方与 9 等分；9 方图基于奇数平方的螺旋扩张；六边形图基于每圈递增 6 的环状扩张；360° 圆图基于圆的多重等分。独立方法给出相同结论，等价于多次独立测量相互验证，可显著降低单一方法的系统性偏差。这与现代量化中的「多因子交叉验证」在逻辑上同构。

#### 模型公式

```
144 主方图：12² = 144，9 等分，含 20736 单位
强阻力：1/4、1/3、2/3、3/8、1/2、5/8、3/4、7/8、144
9 方图：1/81/162/243/324（每级 +81）
六边形：1/7/19/37/61/91/127/169/217/271/331/397
圆图：5⅝、11¼、22½、45、90、120、180、240、270、360
```

#### 3. 适用场景与失效边界

| 维度 | 具体表述 |
|---|---|
| 常态规律 | 多图交集**通常**比单图给出的价位更具支撑或阻力效力。 |
| 环境要求 | **在**价格刻度与图表比例统一**条件下**交集才有意义。 |
| 失效条件 | 当价格超出图表刻度范围（如需叠加多个 144 方图）而未正确换算时，交集**失效**。 |
| 不适用场景 | 缺乏足够历史顶底数据标定起点的品种**不适用**。 |
| 适用范围 | **仅适用**于作为候选区筛选工具，入场仍须角度线与信号日确认。 |

#### 4. 避坑警示
多图互证的价值在于「独立」，若四张图都从同一顶底、同一比例推导，则只是同一结论的四种写法，不构成互证。
